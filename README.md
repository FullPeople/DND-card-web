# DND Card Web

左边是角色卡，右边是规则资料。卡片在需要填写的位置给出提示，玩家查阅并拖入条目，逐步完成角色。

开发目标：完整网页端先行，之后由 C++ 桌面客户端复用界面、数据和规则。当前处于开发阶段，完成状态以 [验收清单](docs/ACCEPTANCE.md) 为准。

- 沿用原 Godot 角色卡布局和 StyleBox 视觉设计。
- 同时支持 2014 / 2024，条目保留来源与版本。
- 连接用户指定的 5e.kiwee.top 资料源，支持本地缓存与自定义扩展。
- 原位缺项提示、拖拽填写、选择约束、来源追溯、撤销和恢复。
- 角色本地保存、审卡导出、枭熊角色卡 JSON 交换。

```sh
npm ci
npm run dev
npm run check
npm run test:e2e
```

本仓库的原创程序代码以 MIT 发布。第三方规则正文、译文及图像不因该代码许可证而获得再授权；资料由使用者配置的数据源提供，不随源码仓库分发。角色数据保存在本机，不会自动上传。
