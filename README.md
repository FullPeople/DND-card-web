# DND Card Web

左边是角色卡，右边是规则资料。卡片在需要填写的位置给出提示，玩家查阅并拖入条目，逐步完成角色。

**[打开在线角色卡工坊](https://fullpeople.github.io/DND-card-web/)** · [验收记录](docs/ACCEPTANCE.md) · [规则覆盖范围](docs/RULE-COVERAGE.md)

网页端先行，之后由 C++ 桌面客户端复用界面、数据和规则。首版是引导手动选择的完整网页工作区；特殊规则的自动适配范围单独记录，不声称模拟所有 D&D 规则。

- 沿用原 Godot 角色卡布局和 StyleBox 视觉设计。
- 固定 A4 纸张，区域内滚动；主要 / 特性 / 背景 / 法术 / 背包五页切换。
- 技能与豁免归入对应属性框；整格虚线提示缺项，点击跳转填写；快捷栏固定常用条目。
- 紧凑列表与冻结标题正文同时展示；全局搜索、多维筛选、跨分类返回、怪物图鉴。
- 左卡悬停在右侧临时查阅；右侧关键词支持嵌套固定提示。
- 职业水印、18 种可叠加状态效果；编辑模式恢复正常布局。
- 来源中文名、逐条启停、配置码导入导出。
- 同时支持 2014 / 2024，条目保留来源与版本。
- 连接用户指定的 5e.kiwee.top 资料源，支持本地缓存与自定义扩展。
- 手动填写、编辑模式、自定义拖拽、来源追溯、撤销和恢复。
- 角色本地保存、审卡导出、枭熊角色卡 JSON 交换。
- 首次联网加载后支持断网重新打开；浏览器多标签页避免互相覆盖记录。

## 使用

1. 在“角色簿”创建 2014 或 2024 角色，填写基础属性。
2. 在“规则与扩展”勾选允许使用的书籍，或导入自定义 JSON 规则包。
3. 点击卡片虚线格，查阅右侧资料并拖入；开启卡片右上角的编辑模式后调整属性、熟练和计算修正。
4. 升级时直接修改职业等级，资料关联的固定特性随等级带入；选项和熟练由玩家自由填写。
5. 特殊效果可人工核对；“数值依据与人工修正”记录最终数值及理由，法术位和使用次数单独记录。
6. 定期下载“角色完整备份”。DM 审卡 HTML 可离线打开并打印为 PDF。自定义包可单独导出。

资料更新只更新右侧目录，不改写已经选入角色的快照。需要采用新条目时，移除旧条目后重新选择；可以撤销。

## 开发与自行部署

需要 Node.js 22.12 或更新的兼容版本。Windows 测试默认使用 Edge；CI 使用 Playwright Chromium。

```sh
npm ci
npm run dev
npm run check
npm run test:e2e
npm run build
```

构建结果在 `dist/`，部署到 HTTPS 静态服务器即可；不能直接用 `file://` 打开源文件作为应用。GitHub Actions 完成规则测试、构建及浏览器验收后发布到 Pages。静态构建约 445 KB JavaScript（gzip 约 146 KB），不打包上游规则资料。

数据只存在当前浏览器的本站存储中，清除站点数据会删除角色和缓存。自动备份保留上一次保存；跨设备迁移请使用 JSON 导出。Excel 适配与 C++ 宿主尚属后续阶段。
