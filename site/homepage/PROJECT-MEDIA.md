# 2026-10-10 项目展示更新

当前项目依次为三龙牌、Kiwee、SealChat、FullDice、MusicBoard 和画师，共六项。项目名称、副标题与描述采用用户本轮提供的文案；画师副标题经用户确认保留“还有梅花山链接”。

四段录制来自用户提供的音乐板、桌面骰子、5etool 和三龙牌 GIF。原文件未改动，保留完整内容、时长和长宽比例，网页演示转为 960 像素宽、15 fps 的静音循环 MP4，采用轻度降噪、压缩和文件头前置，并生成 WebP 预览图。四段录像共 2.58 MB，较上一版减少约 49%；每段录像的首个视频数据包不超过 64 KB。大小、时长及校验记录在 review/r9-media-optimization.json。宽屏开屏结束后显示右侧轮播，三龙牌排在第一项，详情默认收起；窄屏打开轮播时也先定位三龙牌。用户打开详情后，宽屏轮播滑动同步切换详情。详情和横幅共用同一视频实例，非当前录像暂停；快速切换产生的旧播放请求不会覆盖新的播放状态。减少动态效果模式使用静态预览。

画师展示使用用户提供的整张画师图。白盛和钟理头像采用用户明确分配的两张剪贴板图片，缩放为 256 像素无损 WebP；来源与校验记录在 review/r7-artist-avatar-exports.json，原图保留。

“关于我”逐字保留用户提供的描述，复用当前角色卡页面的 Ko-fi 链接和微信、支付宝支持图片。收款图片只在打开关于我后加载。来源记录在 review/r7-support-sources.json。

点赞保存到独立服务的 likes.sqlite，每个浏览器每个项目一票，可取消。浏览器身份使用 HttpOnly Cookie；写入需通过同源和 CSRF 校验，服务端去重并限制请求频率。主页接口通过 /api/home/ 转发到独立服务，沿用原有点赞和浏览器身份数据，保留共享的 QQ 登录和角色卡后端。发布前备份接口配置和点赞数据库。

软件仍显示已验证的 Windows 版本、更新日期与真实下载链接，macOS 保留“待发布”。

手机首屏只加载四张 640 像素 logo 图层，背景与按钮特效在开屏结束后加载。骰子资源与计算线程按操作加载，不在首页后台自动下载。轮播先加载当前可见预览图，无须等待全部项目图片；手机使用六张轻量 WebP，合计约 73 KB。静态备用列表在正式轮播加载时保持隐藏，避免重复下载大图。图片完成下载后直接使用，不等待可能停滞的 decode()；临时失败可重试一次。预览图校验记录在 review/r13-mobile-posters.json。

四段轻量录像均保留完整时长与长宽比例，采用 480 像素宽、12 fps 的 MP4，总计约 524 KB。打开项目后先准备当前录像，首帧可用后预加载其余轻量录像；全部轻量录像缓冲完成后，再为当前项目下载 960 像素版本，保持同一视频实例并接续播放进度。高清下载失败时继续使用轻量版本。轻量版本校验记录在 review/r12-media-optimization.json。
