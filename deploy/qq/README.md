# QQ 登录入口

首页、角色卡和卡库共用同一个 QQ 互联网站应用。官方按钮保留原图与原始尺寸，电脑使用 170 × 32，窄屏使用腾讯提供的 120 × 24。

网站地址：`https://dnd.center/`。
回调地址：`https://dnd.center/api/auth/qq/callback`。

`home-index.html` 基于已经上线的首页，只增加登录入口与两个独立资源，保留现有切图、开屏、骰子和全部站点入口。它引用既有不可变首页资源，不用角色卡构建生成的旧首页替换当前首页。

网站服务使用 `/etc/dnd-card-cloud-qq.env` 中的 `QQ_APPID`、`QQ_APPKEY` 和 `QQ_CALLBACK`，文件只能由 root 读取。密钥不进入仓库、浏览器代码或输出日志。未配置时，点击按钮会显示可返回网站的配置未完成提示，不能称为已完成真实 QQ 登录。

在 QQ 互联中保存回调地址和自己的调试 QQ 号，再通过本机配置窗口保存凭据。公网返回腾讯授权页后，用调试 QQ 完成扫码授权，确认首页、角色卡和卡库共享登录状态，然后重新提交审核。真实登录验证需要用户自己操作。

已有临时角色卡不自动转移到 QQ 账号；原上传浏览器的管理权限和全部内容保留。OpenID 不等于 QQ 号，不允许把用户手填的 QQ 号当作已验证身份，因此按数字 QQ 号授予编辑权限仍需独立的身份验证方案。
