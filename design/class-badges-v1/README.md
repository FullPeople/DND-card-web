# 职业徽章 · 第一稿

已接入卡面中央水印；运行时资源位于 src/assets/class-badges，映射位于 src/ui/classBadges.ts。按当前中文站职业索引去重，共 17 种身份：12 个基础职业、奇械师、秘术师与 3 类协力者。同一职业不同规则版本共用徽章。只显示最高等级职业，并列取角色职业顺序最前的一项。

每枚 SVG 使用 64 × 64 坐标、单一 currentColor 填充及透明负形，无描边、渐变、阴影或外框。index.html 为对照页，展示大图和 24 px 样例，并可切换深浅底。manifest.json 记录名称与设计意象。

这些是项目自绘方案，并非官方徽章。独立 SVG 可继续调整，不绑定角色规则数据。
