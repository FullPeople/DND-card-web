# 状态视觉第二版 · 本地已实现

此版覆盖第一稿。全部效果可同时出现，进入编辑模式时过渡恢复正常外观/位置，退出时恢复状态效果。五个页签共享状态、职业水印与框体效果；详细页提供紧凑先攻、速度、头像框。状态气泡放在 DND 五版角色卡标题右侧，死亡豁免放在熟练加值上方。

| 状态 | 视觉行为 |
| --- | --- |
| 倒地 | 头像框过渡倒转 180 度，解除时回正 |
| 耳聋 | 纸张右侧约 1/4 高度处显示禁扬声器图标，约水印一半大 |
| 昏迷 | 速度框全黑；同时继承失能和倒地 |
| 恐慌 | 全部框边小幅持续抽动；输入、布局和碰撞位置不抖动 |
| 力竭 | 框的实际周长六等分，1～6 层逐段染红；气泡旁调整层数 |
| 麻痹 | 间歇低强度故障色块与闪屏；同时继承失能 |
| 魅惑 | 背景层曲线藤蔓沿整张纸边生长，爱心与卷须展开；框与文字在其上方，移除时收回 |
| 目盲 | 纸张右侧约 3/4 高度处显示禁眼睛图标，约水印一半大 |
| 失能 | 框体竖直受重力下落，框间和纸张底部碰撞堆积；实际点击/拖拽区域随框移动；解除时回位 |
| 石化 | 各框增加裂纹、轻微灰化；同时继承失能。落稳后石化纹理静止 |
| 受擒 | 更大的手从左右扣住卡片，移除时向外松开 |
| 束缚 | 多条铁链从边缘伸到纸张另一端，没有中途截断；解除时缩回 |
| 突袭 | 先攻框四周一整圈锐角放射片，弹出/收回 |
| 隐形 | 所有实线框变为静态虚线，原有缺项动画虚线保留；头像淡化 |
| 浴血 | 全纸多处红色飞溅，加入/移除过渡淡入淡出 |
| 震慑 | 头像附近星星沿椭圆轨道旋转；同时继承失能 |
| 中毒 | 各框边缘绿色墨水浸染与不规则滴痕，纸张外围轻微染色 |
| 专注 | 职业水印下方魔法阵持续旋转，使用职业 SVG 图形遮罩挡住图案覆盖处 |

视觉继承仅使用用户确认的组合，不增加角色条目、不执行状态规则、不改写速度等数值。重复来源只画一份；移除一个来源或复合状态时仍检查其他来源。力竭使用状态条目的 level 手动记录，不推断规则版本的层数。

失能保留框的横向中心位置，用竖直重力堆积；部分小框以固定的正负角度轻微倾斜，并以旋转后的包围范围参与碰撞和纸张边界限制。空间不足时自动减小角度。编辑恢复同时回正。恐慌不移动实际输入控件。状态条在主要页下落期间移至上方空位以保持可用；编辑开关始终可操作。减少动态效果偏好下展示静态结果并停用闪屏和循环动画。

职业水印只选择等级最高的职业，并列选最前一个；移除/替换时先播放旧图退场，再出现新图。同一时刻只有一枚。无职业时专注魔法阵仍可独立显示。

实现：src/ui/cardVisualState.ts、CardAtmosphere.tsx、CellArt.tsx、useCardGravity.ts、cardAtmosphere.css。浏览器验证包含五页状态叠加、碰撞无重叠、控件命中、复合状态撤回、编辑复位和职业退场。
