# Wiki 明确条目链接的整合回归

最终整合的远端检查复现：从 2014 职业正文点击明确的 2024 关联重印后，链接仍保留 2014 筛选；严格条目标识解析因此拒绝显示目标，页面变空。首次失败保留，不能把构建通过当成阅读流程通过。

明确点击资料时，仅在当前版本筛选不能显示该条目时切换到可显示它的版本；原筛选允许显示时保持。地址与状态同时更新，刷新和浏览器返回仍读取同一个来源、定义与版本。玩家主动更换筛选后，原有隐藏／恢复语义保持。

“复制链接”同步保留当前定义的标识，避免同名、同源不同正文再次变成旧歧义链接；未指定定义的旧链接继续要求玩家选择。检查覆盖宽窄屏复制、重开、显式重印切换与返回，以及原有歧义和冲突正文读取。

本次只修改独立 Wiki 的导航，不修改 77 个绑定的规则运行文件；完整冻结输入回放按同字节来源复用。最终准确提交的完整检查、构建与远端 CI 单列，未部署。
