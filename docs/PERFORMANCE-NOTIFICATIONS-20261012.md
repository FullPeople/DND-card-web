# 云端变更通知检查点

第二批候选代码接入云端变更通知：网站账号、账号二级弹窗和卡库共用一次等待请求；房间卡按已有房间凭据订阅。收到通知后重新走权限检查和原卡读取，通知不携带角色正文。原有定时读取保留，用于旧后端、断线和漏消息恢复。

后端每次最多等待 20 秒，限制并发连接、账号连接和房间范围。切换账号、房间凭据或关闭页面会取消等待。读取期间再次收到通知会补读，旧账号的迟到响应不能更新新账号界面；读取失败不能推进通知游标。写入仍使用原有权限、修订号和冲突草稿逻辑。

## R1／R2 保存与范围隔离候选

已读取审计会话的冻结复核、四个独立竞态场景和结构化清单。保存操作现在记录原账号／房间证明作用域，CSRF 等待后再次核对；成功回执只确认正文与原操作，不授予权限。旧作用域的成功、拒绝和未知结果不能更新新作用域的权限；同正文修订的重新上锁也不被旧回执撤销。未知结果只在原作用域核对原修订号和完整载荷，切换后保留原草稿和操作状态。持久化记录仅包含作用域 SHA-256，不写入令牌或房间证明。

qqRoom 和新插件宿主使用六秒授权期限。只有当前作用域被接受的授权读取可以续期，保守起点为该读取发出时。超过六秒才到达的响应不能重新开放写入；CSRF、通知、保存回执均不续期。独立计时器更新只读状态，每次发送前再同步核对，后台计时节流或三十秒请求等待不能绕过保护。作用域变化与前台恢复先进入待核验；有效新读取后恢复，明确拒绝进入只读，过期进入待核验。本机草稿继续保留。

Suite 通知组因单个证明失败时，用最多四路、单次一秒的授权摘要读取定位失效范围，只将有效范围重新订阅。明确失效范围三十秒后复查，暂时连接失败五秒后复查；换证明、重新连接及显式重试可提前恢复。通知后按卡独立读取及发布，一张卡读取失败不会取消其他卡的发布；宿主云卡读取有五秒独立截止，失败卡禁写。旧插件已移植范围恢复并在房间证明变化时立即重建订阅，其完整卡库／绑定／信息面板仍未验收。
