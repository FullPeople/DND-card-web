# 云端变更通知检查点

第二批候选代码接入云端变更通知：网站账号、账号二级弹窗和卡库共用一次等待请求；房间卡按已有房间凭据订阅。收到通知后重新走权限检查和原卡读取，通知不携带角色正文。原有定时读取保留，用于旧后端、断线和漏消息恢复。

后端每次最多等待 20 秒，限制并发连接、账号连接和房间范围。切换账号、房间凭据或关闭页面会取消等待。读取期间再次收到通知会补读，旧账号的迟到响应不能更新新账号界面；读取失败不能推进通知游标。写入仍使用原有权限、修订号和冲突草稿逻辑。
