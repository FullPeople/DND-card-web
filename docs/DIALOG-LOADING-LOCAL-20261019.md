# 常用弹窗加载，本地修复

用户报告规则与扩展、导入与导出先出现空弹窗，公告出现 CSS 预加载错误，并要求移除新增的生命、攻击／资源、法术手机快捷栏。本轮继续在 P0～P3 隔离候选上修改，不推送、不部署，不清理或迁移浏览器角色数据。

## 改动

- 原来点击前的动态导入与 React 懒加载使用不同的就绪状态。下载完成后第一次挂载仍可能进入 Suspense 占位。现在常用窗口共用组件缓存，提前准备完成后直接渲染完整内容；首次未准备完时保留原卡面，等待后再打开窗口。
- 在首屏实际揭开之后，优先准备规则、来源、导入导出和公告。悬停、键盘聚焦、触屏按下也可提前准备；共用一次进行中的下载，不挂载隐藏编辑器，不复制或固定角色数据。准备失败后，明确打开操作可以重试。
- 公告本身的少量样式随首屏加载；自动化进度样式只随对应页读取。公告增加错误边界，读取失败不卸载整个角色卡。检查时旧报错所指文件仍在，但 5317 已无监听，不能仅凭该报错断言原文件打包遗漏。
- 删除应用中的手机快捷栏入口，保留纸卡原有生命、武器、资源和法术操作。灰色切角、五页、默认 A4、显示偏好和 JSON 格式继续保留。
- 本地预览恢复为隐藏运行的独立进程。更新预览时先补新资源，保留旧资源，再替换入口，避免已打开页面继续引用旧文件时找不到资源。
