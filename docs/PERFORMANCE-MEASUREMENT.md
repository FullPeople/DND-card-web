# 可重放的交互计时

`playwright.interaction.config.ts` 使用本机隔离后端和新建 Edge 上下文，不读取玩家浏览器资料。测试入口是 `tests/e2e/interactionPerformance.spec.ts`；输出位置由 `PERF_TIMING_FILE` 指定，默认放在任务证据目录。

一次正式运行每个操作包含一次首次打开和 30 次热切换。浏览器捕获实际点击事件，以内容出现并经过两帧作为完成时间，同时记录最初反馈、长任务、失败及当时资料是否仍在加载。汇总保留 P95、最大值、失败数和全部样本。一次首次打开不是冷启动 P95，冷启动仍须使用独立上下文另外采集足够样本。

## 条件

| 环境变量 | 含义 |
| --- | --- |
| `CLOUD_PREVIEW_ROOT` | 指定被测生产包，支持旧包只读对照；不覆盖旧包 |
| `PERF_SAMPLES` | 热切换次数，默认 30；1 仅用于工具自检，最多 100 |
| `PERF_CORPUS_ROOT` | 使用已有公开资料快照目录；逐份验证内容哈希，记录可用文件、实际回应文件、缺失请求和索引哈希 |
| `PERF_CONSUMER_ADAPTER` | 本轮真实消费者适配器，用于生成复杂测试卡；须保留其源码与核对身份 |
| `PERF_CARD_COUNT` | 1–300 张隔离测试卡，要求已有快照和适配器；依次扩大，不能直接跳到最大档 |
| `PERF_INTERACT_EARLY` | 为 1 时在资料尚未完成加载时开始操作，逐样本记录是否仍在加载 |
| `PERF_PROFILE` | `normal`、`standard150`、`network150`、`network300`、`cpu4`；分别为回环网络、150 ms／10 Mbps、150 ms／1 Mbps、300 ms／1 Mbps 和 4 倍 CPU 限速 |
| `PERF_SOURCE_ORIGIN` | 已校准的本机 HTTPS 资料服务地址；网络测量必须设置，禁止用直接回应冒充限速下载 |
| `PERF_AVATARS` | 默认使用固定种子生成的 256 × 256 PNG 测试头像；为 0 时只用于与旧无头像场景复核 |
| `PERF_CAPTURE_CPU` | 为 1 时额外记录浏览器 CPU 采样，单份上限 100 MiB |
| `PERF_CONTENTION` | 记录当时其它占用资源的任务；正式前后对照应避免构建与全量核对并行 |

复杂卡混合空白卡、五级施法角色和较大法术列表／长笔记／PNG 头像角色。它们由公开快照生成，不复制玩家卡。三张自检卡的选项数为 0、37、117，总 JSON 大小约 376 KiB；这只是软件输入，不能据此宣布三人房间或真实大卡量已通过。

本机资料服务入口为 `tools/performanceCorpus.mjs`，只监听回环地址，输入快照与临时证书从环境变量指定，结束时向标准输入发送 `stop`。测试不提交规则正文或证书。

使用 `PERF_SOURCE_ORIGIN` 时，公开资料请求转向同协议的本机 HTTPS 服务，229 份输入逐份核对哈希，CDP 网络限速覆盖实际下载。自签名证书例外只适用于隔离测试上下文，没有修改系统信任或线上 TLS。150 ms／1 Mbps 的 100,372 字节校准包，真实 HTTP 中位约 1,000 ms，直接测试回应约 8 ms；网络配置缺少真实资料服务时测试会拒绝执行。旧直接回应记录仅测处理成本。真实上游线路、QQ 服务、房间 SDK 和跨端收敛另行计时。

首次数据加载与首次界面打开都保留；发生准备或操作失败也写报告。CPU 记录与原始计时属于诊断证据，不能用正常退出替代性能预算、真实登录或多人验收。
