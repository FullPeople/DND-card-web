## 改了哪些内容

- **变化对象：** 姓名、玩家名、年龄、性别、阵营、人物形象、故乡、身高、体重、背景描述、个性、理念、羁绊、缺陷及背景故事，共十五个实际输入栏。只复制顶层和有变化的文字小对象；未变的选择、来源快照、配置、资源及未知资料保留引用和内容。同值输入在写历史前返回。
- **真实依赖：** 已明确登记的文字意图复用同一不可变规则构造与同一来源上下文中的核对结果。未登记回调、未知字段、其他角色、版本／来源／规则变化继续失效并走正常计算，不能通过历史标签或同名字段冒充文字动作。
- **遗漏的读取者：** 背景页已隐藏的页头提前返回；状态栏传入现成目录，避免重新构造选择。法术、选择工作区及相关数值控件复用当前卡已算结果。独立挂载或可变预览没有永久对象缓存，改变机制后仍计算当前值。
- **资料归属：** 读取视图覆盖最新文字及实际变化的余额，避免盖回旧文字或把旧卡尚未初始化的余额盖在完成初始化的视图上。弱引用构造标识不写入存档、网络协议或角色 ID，不跨卡授予缓存资格。
- **撤销恢复：** 文字历史只对变化字段做三方合并，保留并发扣费和其他文字；同字段冲突继续拒绝。资源、持有物和账本保护仍执行。普通机制历史及工作台／QQ 房间保留原规范化流程。
- **权限和同步：** 编辑、撤销提交继续读取当前角色及当前授权；数值缓存不包含写权限或扣费授权。新文字对象仍取得新的正文散列；拒绝上传保留草稿与余额，迟到确认不能盖回后续文字。

**存档格式、整本持久化、跨标签页广播和云端同步协议沿用原流程。** 本批没有按字段发送协议或按卡数据库迁移。其他标签页的接收重读、库存普通修改、首屏和其他机械操作的重复协调，仍是后续任务。
