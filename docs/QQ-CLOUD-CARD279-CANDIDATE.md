# QQ 云端卡 279 候选

网站卡库修复前后切换及两侧进出场动画，账号操作收进右上角弹窗，移除左侧重复账号及卡库公告、调色盘。

新版枭熊使用标准 QQ 登录图标。未登录直接连接 QQ；登录后打开二级弹窗选择、导入和管理卡。云端原卡经过既有 JSON 校验导入当前角色簿，直接使用原工作台五页编辑器；无嵌套浏览器。名字和角色簿显示云图标，右上角云按钮显示当前账号权限。卡主可以解锁给房间或授予、撤销已登录账号的编辑权。未获授权的 DM 只读。房间改动自动写回原卡，移出房间保留原卡及身份。

修正 QQ 订阅的空参数在 JSON 传输后被误拒绝的问题。个人令牌只留在玩家自己的后台，弹窗通过受限通道读取；房间资料中不存个人令牌。当前云端卡轮询使用修订号，无改动时返回简要权限信息，不重复生成完整角色文档；未选中的云端卡不随心跳反复加载。

上线范围：网站 card/library、新版 Suite-dev 和云端 API；稳定插件、旧浏览器卡站、首页及三龙牌保留。原脏工作区不打包。最终源码审计、CI、独立备份及公网核验尚待完成。真实 QQ 扫码、真实房间与实体设备验收单独记录，不以合成浏览器流程代替。
