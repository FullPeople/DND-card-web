# QQ 卡库入口修复候选

新版工作台位于独立标签页。此前“我的 QQ 卡库”请求在原枭熊房间页打开弹窗，当前标签页没有显示卡库。按钮现在直接打开工作台内的卡库页面，再次点击或关闭卡库会返回之前的工作区。

配套 Suite 将原 QQ 卡库页面接入工作台内的房间通信。该通信仅允许读取、更新和订阅 QQ 房间卡信息，不暴露插件账号凭据、其他房间信息或场景写入接口。

本次只发布新版插件；网站、后端及稳定插件保留已发布版本。规则消费者模块与原审计一致，复用经核对的报告。卡库入口、连接账号、加载五页编辑器及关闭返回使用实际构建界面测试；合成账号和房间接口不代表真实枭熊房间已验收。最终发布结果见上线回执。
