# 旧卡资料批量同步 · 233 本地候选

2026-10-02，基于 `codex/direct232-followup-20261002` 的第三批修复继续实现。没有合并 main、部署或修改玩家存档。

## 最新流程

- 原六步改为两步：核对基础资料 → 整卡同步预览。职业、背景、种族、子职确认后，一起处理声明气泡、普通/来源法术、背包资料及可唯一关联的训练引用。
- 来源更新保留原 Selection ID、等级、装备数量/状态、预备记录、熟练、选择答案、手动数值与既有消耗。来源明确已撤销的旧声明在预览中统一列出。
- 自定义、多个匹配、缺失资料与不再适用的选择内容，进入紧凑多列网格，默认保留，逐项勾选/取消。保留内容不会被下一次常规来源刷新悄悄删除；取消某个父项不会连带删除仍勾选的子项。
- 声明缺失或歧义不当作“旧内容应删除”。已主动移除的可对应气泡跨版本继续保留删除状态；无法安全对应的项目可见，未猜选。明确取消保留的来源法术写入删除回执，资料稍后恢复也不复活；版本切换自动退场的旧法术不写该回执。
- 最终预览汇总资料替换、增删、数值、资源及警告。返回后重新计算；预览期间原卡变化会阻止使用旧计划。保存继续沿原有副本事务，保存失败可重试，结果不确定时不重复创建。
- 同步不再次发放起始装备/钱币，不补满资源。自动计算关闭时也预存新声明的零余额历史，后续重新开启不能把这次同步当作休息。
- 没有实现仍待单独确认的旧卡种族基础属性拆分转换；既有基础分与所有权标记原样保留。
