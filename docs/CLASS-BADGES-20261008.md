# 职业图标更新

用户提供的 `图标.psd` 为 1000×1000 画布，包含背景层和 11 个独立职业图层。只导出职业图层，不导出背景、不重新绘制，也不将 PSD 原文件放入公开仓库。

已替换野蛮人、吟游诗人、牧师、德鲁伊、战士、游侠、游荡者、圣武士、术士、魔契师、奇械师图标。PSD 中的“圣骑士”对应产品中的“圣武士”。武僧、法师、秘术师以及专家、施法者、武者协力者继续使用原图标。

输出为透明 RGBA PNG，统一为 512×512。按透明通道裁出图案，保持比例缩放并居中，最长边 408 像素，四周至少留空 52 像素。内部镂空保持透明，支持角色卡现有蒙版调色。11 张图标共 194,277 字节，单张约 11–21 KB；构建生成独立带哈希资源，只加载当前展示的职业图标。

提取脚本为 `tools/extractClassBadgePsd.py`，本次使用 psd-tools 1.24.0、Pillow 12.3.0。可在隔离 Python 环境中运行：

```text
python tools/extractClassBadgePsd.py SOURCE.psd src/assets/class-badges docs/data/class-badges-20261008.json
```

`docs/data/class-badges-20261008.json` 记录源文件与输出文件 SHA-256、图层范围、透明通道范围及留空规格。修改共用的图标映射，独立站、卡库预览和枭熊插件从同一份 Web 源码构建时会使用同一组图标；实际发布状态以各渠道发布凭据为准。
