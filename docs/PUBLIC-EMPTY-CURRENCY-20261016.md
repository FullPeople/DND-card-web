# 公共仓库零余额货币格补修

2026-10-16 重新核对 2026-10-01 的邮件“Bug反馈：新版插件”：已有有余额货币转入公共仓库后，转回仍留下零余额货币格。当前 UI 隐藏所有货币的移除入口，Suite 宿主同样拒绝所有货币删除，因此旧格子无法清理。

只允许在公共仓库移除余额为零的货币行。UI 和宿主同时限定，继续执行原有可读权限、容器锁、条目锁和 expected revision 校验；GM 也不能移除有余额货币。角色钱包的零余额货币仍保留。先转回钱币，再手动移除空格子；不迁移、扫描或自动删除玩家资料。

Web 实际 StockBoard Chromium 七项检查先出现两个预期失败，修复后全部通过；覆盖移除入口、有余额、角色钱包、容器锁、条目锁、连接不可用和 GM 清理。Suite 实际纯事务模型七项检查通过，额外覆盖余额守恒、并发充值拒绝旧请求、去重和输入不可变。对应配置加入既有 CI。
