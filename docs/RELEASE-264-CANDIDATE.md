# 264：Wiki 收藏与就地选择

本批从实际 Web 262、新版枭熊 263、稳定版 1.3.21 隔离制作，原混合目录及上一版骰子提速修复保留。用户已授权实现、验证、合并和部署；只有缺少实际权限或必要信息时才询问。

- Wiki 增加收藏分类。右键收藏和移除，按浏览器持久保存，不写入角色或房间规则；收藏仅保存完整身份，不保留规则正文。版本、来源及当前房间读取权限继续生效。
- 虚线选项在非编辑模式可打开，自动进入编辑；工作区位于当前特性框，保留当前页、A4 偏好和其他数值，内容独立滚动。
- 忽略仅记录展示确认，不改变答案、规则成立条件、资源或真实填写进度。全部选择完成或忽略时自动收起；右键重新选择和恢复填写可以继续修改。
- 核对并同步旧卡后忽略当前未填项；仍先保存完整旧卡副本，再更新当前卡，原 ID 和绑定保留，失败保留草稿。
- 受限筛选和当前职业页签持续显示流动提示，选中背景与文字保持对比；全局搜索按规则基础版本及兼容设置过滤。
- 新版工作台同步全部功能；稳定版仅配套五页查看器与公告，不整合新版宿主。枭熊不接独立站云端。

预期网站和卡库 1.0.264／公告 0.1.53、新版工作台 1.0.264-dev、稳定版 1.3.22。当前尚未发布，以最终发布回执为准。

验证包含身份和存档数据测试、实际浏览器点击／拖拽／刷新与切卡、原 229 份输入的完整运行核对、精确提交 CI、正式包与各入口的公网复核。真实 QQ 扫码、真实 GM／玩家房间和实体触屏不能以合成检查代替。

只发布 card/library 和 suite-dev/suite 的静态文件，每个目标创建本轮独立备份，并核对玩家数据、首页、三龙、Nginx、SSH 及后台保护状态。不修改后端和网络配置。
