# 资料条目标识冲突候选

部分资料共用英文名称、来源和旧标识，但中文名称、规则版本、归属或正文不同。旧目录按标识存入 Map 后会覆盖前一条，缓存重开也会丢失。此候选保留没有冲突的旧标识，对实际冲突补充定义标识，并重建旧的解析目录缓存；原始文件缓存和角色卡不因此清空。

## 行为

- 区分 2014／2024、职业与子职归属、具名版本和同源不同定义。标识与输入对象属性顺序、同批记录排列顺序无关。
- 同名同源的规则正文冲突时保留两条并提示，自动效果默认不可用；需要对具体定义作出明确例外。只差图片或背景资料的记录仍可阅读。
- 引用必须唯一匹配。旧链接有多个候选时提供选择，新链接能重新打开选定定义；不会任选第一条。引用类型和实际归属仍受约束。
- 已存角色卡继续使用原快照、选择和资源消耗；别名匹配核对完整定义。具名版本仍受原专长不可重复规则约束，不借新标识重复授予。
- 来源正文不能伪造内部迁移标记。源数据只读，规则计算保持纯函数。
