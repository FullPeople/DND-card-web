## 候选修改

- “资料浏览”独立于角色卡计算规则，可同时查看 2014 与 2024；只读用户也能调整资料版本和简写。实际修改角色或房间规则仍要求原有写权限。
- 云端卡缺少编辑权时显示实际原因，不再误称另一标签页正在编辑。使用既有紧凑黄色提示，避免重复横幅。
- 选中状态覆盖 `aria-checked` 单选按钮。QQ 卡库弹窗增加规则版本筛选。
- 调色盘说明角色卡配色不能修改的原因，个人界面和 Wiki 配色仍可调整。窄屏调色盘入口固定在工具栏右侧。
- 新旧枭熊工作台分别补充个人配色偏好的宿主保存；新版增加合法主题、夜间和颜色值核对，旧版保留自身结构。设置回复经过宿主核对后，独立角色卡页面同步自己的界面配色。
- 枭熊云端卡弹窗使用统一弹窗结构，分别展示卡片归属、当前权限、授权和操作。卡主、授权编辑者、房间授权成员和只读用户的权限保持原有边界。
- 角色簿拖影复制完整角色行，保留头像、云图标、数值和操作栏，并按实际抓取位置跟随；取消拖动保留顺序。
- QQ 会话仅合并同时发生的展示读取，不缓存写操作的授权。切换账号通知使旧请求失效；写入仍单独读取服务器会话。卡库目录携带响应所属账号，客户端拒绝跨账号的迟到目录。
- 云端自动保存不再因父组件每次生成新的读取回调而重新排队，减少打开 Wiki、设置等操作引发的无关同步工作。

训练名称索引改为在原数组中追加，保留两种名称、资料顺序及版本身份。页签首次加载时在原角色卡区域显示状态，弹窗保持标题和关闭入口。云端权限回归和工作区锁回归已分别加入对应的浏览器检查配置，实际执行尚待有效候选包。
