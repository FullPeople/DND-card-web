# 性能与权限优化：2026-10-12 检查点

持续目标已启用，收尾条件沿用 [完整计划](PERFORMANCE-CLOSEOUT-PLAN.md)。本页记录第一批候选修改，不代表已经发布或完成真实房间验收。

## 候选修改

- “资料浏览”独立于角色卡计算规则，可同时查看 2014 与 2024；只读用户也能调整资料版本和简写。实际修改角色或房间规则仍要求原有写权限。
- 云端卡缺少编辑权时显示实际原因，不再误称另一标签页正在编辑。使用既有紧凑黄色提示，避免重复横幅。
- 选中状态覆盖 `aria-checked` 单选按钮。QQ 卡库弹窗增加规则版本筛选。
- 调色盘说明角色卡配色不能修改的原因，个人界面和 Wiki 配色仍可调整。窄屏调色盘入口固定在工具栏右侧。
- 新旧枭熊工作台分别补充个人配色偏好的宿主保存；新版增加合法主题、夜间和颜色值核对，旧版保留自身结构。设置回复经过宿主核对后，独立角色卡页面同步自己的界面配色。
- 枭熊云端卡弹窗使用统一弹窗结构，分别展示卡片归属、当前权限、授权和操作。卡主、授权编辑者、房间授权成员和只读用户的权限保持原有边界。
- 角色簿拖影复制完整角色行，保留头像、云图标、数值和操作栏，并按实际抓取位置跟随；取消拖动保留顺序。
- QQ 会话仅合并同时发生的展示读取，不缓存写操作的授权。切换账号通知使旧请求失效；写入仍单独读取服务器会话。卡库目录携带响应所属账号，客户端拒绝跨账号的迟到目录。
- 云端自动保存不再因父组件每次生成新的读取回调而重新排队，减少打开 Wiki、设置等操作引发的无关同步工作。

## 已有证据

本机类型检查通过；会话时序、同步、后台、QQ 登录、权限和配色六个测试文件共 83 项通过。新旧工作台个人偏好各 7 项检查通过，未写房间元数据。这些都是软件夹具验证。

对发布 284 的既有生产包，隔离浏览器复现四项回归：错误的标签页提示、简略拖影、个人配色不重绘、窄屏调色盘出界。390 px 用例中，调色盘按钮右边缘为 462.56 px。原始报告、截图和交互轨迹保存在任务证据目录；未复用玩家浏览器资料。

最初的候选生产构建被严格覆盖检查拒绝，原因是 `App.tsx` 的消费者字节改变，旧覆盖报告不再适用。已经复用现有 229 份资料输入，启动完整 18,789 身份重审；未修改覆盖定义或降低守卫。新的完整报告和候选界面复测仍待完成。

服务器两轮只读采样均完成，每轮 120 个样本、约 10 分钟。第一轮可用内存 564–599 MiB；两轮交换空间均未使用，七项服务持续正常，没有新增内存溢出计数。两轮中间有间隔，此记录不是 30 分钟真实玩家稳定使用验收。
