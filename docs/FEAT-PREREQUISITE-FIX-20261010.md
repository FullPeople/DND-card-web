# 专长前置条件修复

背景已授予起源专长时，四级后续专长仍被标记为“此前置条件仍需手动核对”。本轮根据结构化专长引用检查角色已拥有的专长，核对来源、版本、启用状态及完整父项链。失效父项、缺失父项和循环引用不能满足条件；等级及其他未支持前置条件保持原有边界。

逻辑不按具体专长名分支。原创回归验证选择、原生保存往返、不同来源、版本不符、停用和失效父项；现存资料回归验证“竖琴手特工 → 竖琴手协同”。桌面与窄屏浏览器各验证选择后刷新保留，连同原职业学习流程共 4 项通过。窄屏检查返回角色卡后验证，职业与专长两处均有选择入口时使用对应区域定位。

Data [PR #22](https://github.com/FullPeople/dnd5e-automation-data/pull/22) 已合入并通过合并提交检查。本地锁定其报告提交 `f2234e9471f847be6d053122718592bdc1399c7e` 的原始 Git blob。229 份资料、18,789 个身份、4,561 项审阅和 6,535 项部分实现见证保持不变；全部逐项状态与见证未改变。62 个消费者模块的实际字节核验通过，不把具体前置情境的修复升级为整条规则完成。
