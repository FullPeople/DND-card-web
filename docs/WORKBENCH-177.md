## 本轮 18 项行为

1. 连接状态占用固定高度，不因“正在重新连接枭熊”而推挤功能栏和卡片。
2. 选中棋子与切卡独立于完整角色簿加载。旧读取不能抢回新选择；怪物缺少场景快照时按来源读取目标与继承依赖，不等待全部怪物库。
3. 总览／投骰／音乐保留独立按钮行，角色卡标签另起一行，缩小文字，去掉可编辑／当前场景等重复说明。长行支持滚轮和拖动横移，隐藏滚动条。
4. 数值资源输入失焦或回车提交，不额外生成确认勾号。
5. 公共仓库标题右侧显示锁定按钮。DM 可以上锁／解锁；未上锁时玩家可以操作，权限仍在宿主与库存事务层校验。
6. 设置与功能开关的结构、颜色配置先在本地显示；共享变量取得真实值前，对应原位控件不可操作，不插入等待段落。嵌入主题在 HTML 首屏生效，移除旧深蓝闪现。鸣谢保留字号规则，使用顶部三轨从右向左飘过，离开设置即消失。
7. 玩家规则页采用紧凑只读概述，显示房间规则启用情况、已开启扩展及其中单独禁用的内容。来源名称的纯文本／简写／二者显示方式由玩家本机决定，不回写房间规则。
8. 职业“子职”开关打开后，正文连续展示各子职，右侧目录依次列出子职；取消占据大块区域的子职按钮群。关闭后恢复主职业正文与目录。
9. 恢复枭熊场景右下角的常驻骰子记录窗口，沿用原有骰子记录与显示设置。
10. 卡片区域不足 560 CSS 像素时，人物五页与怪物卡切换成正常字号的纵向阅读排版，页签位于上方。宽屏保留 A4；打印／PNG 导出临时恢复 A4，再恢复当前窄屏布局。
11. 自定义内容选择背包物品类型时提供价格与重量字段，并保存在条目原始数据中，供物品格与负重使用。
12. 公共仓库物品拖向玩家资源卡时以紧凑物品格落位，接收区域高亮，不把物品铺满玩家卡。库存请求保留操作身份，区分处理中、已确认失败和结果尚未确认。
13. 同步传输支持直接窗口通道、失活降级、轻量心跳、增量文档与压缩。重复请求复用处理结果；过期排队操作在执行前拒绝。HTTP 超时不会自动重放修改；未确认本地内容保持可恢复，真实终态回执再决定如何处理。
14. 二级投骰嵌入界面删除旧右上角 ×，保留当前外层关闭与键盘处理。
15. 设置的颜色区域增加本机持久化黑夜模式，覆盖界面、设置、音乐和骰子；角色纸面仍保持原灰色风格。
16. 有头像时，底部设置区域分成替换／删除。删除需要二次确认，头像与背景页独立立绘互不删除。
17. 接通中文站三方／自制内容索引，按文件去重、读取来源中文名和书籍版本，导入职业、子职、法术、物品等内容。第三方内容仍受规则与扩展中的启用配置约束；来源身份不会按同名条目合并。
18. 旧版角色优先保留原文件地址与房间目录，避免先等整个角色簿才能打开单卡。无版本旧数据按现存资料迁移；缺失或读取失败的文件不会生成假角色内容。

## 同步修复依据

完整角色文档仍使用既有角色文件；场景 metadata 是血量、状态、资源等数值的映射；公共仓库和跨角色物品位置仍使用既有库存账本。本轮没有新增另一套持久化服务。

独立复核发现并针对以下路径补强：失活 WindowProxy 阻止降级；快速通道中相同请求重叠执行；后台批量读取复用早先棋子快照，使已经删除的状态被重新合入新文档；迟到失败回执未清理库存乐观草稿；中继请求的回复被已有直连窗口截走。后台校准临近读取并核对实际棋子状态，文档增量仍使用版本／前值校验，不能把“压缩了消息”当成解决并发冲突。

原怪物详情模块已有按源和继承依赖读取能力。工坊此前误走整库读取，因此旧插件预热的缓存会掩盖冷启动等待。177 复用该详情模块，并给选中怪物独立的有界请求通道，避免被批量下载占满请求槽。
