# 赠送法术的声明式筛选选择

本批是独立机制候选，不是整条规则、整本扩展或全目录完成声明。既有 229 份冻结输入内共有 253 处字符串筛选声明，涉及 26 个来源；首批识别其中 11 个来源的 57 处正向筛选。其余条件继续显示待核验，不会省略条件后扩大候选。

## 语法与身份

语法依据为固定镜像提交 `tjliqy/5etools-cn@5cc0bbe2c2b241a334e731af4448bdba2168e8bd` 的 [筛选参数解码](https://github.com/tjliqy/5etools-cn/blob/5cc0bbe2c2b241a334e731af4448bdba2168e8bd/js/render.js)、[同字段默认 OR](https://github.com/tjliqy/5etools-cn/blob/5cc0bbe2c2b241a334e731af4448bdba2168e8bd/js/filter/filter/filter-filter-generic.js)、[不同字段默认 AND](https://github.com/tjliqy/5etools-cn/blob/5cc0bbe2c2b241a334e731af4448bdba2168e8bd/js/filter/filter-box.js) 及 [法术元数据投影](https://github.com/tjliqy/5etools-cn/blob/5cc0bbe2c2b241a334e731af4448bdba2168e8bd/js/filter-spells.js)。不读取规则正文推测效果，不按职业或特性名称分支。

当前接入环阶、八种学派、明确子学派、仪式标记和法术攻击标记。字段之间全部满足，同一字段的分号值满足一项。未知字段、否定、范围表达式、重复字段、非整数数量及其他未核验声明整体保留人工提示。职业法表仍需独立核对来源、版本、变体法表和可选规则授权，暂不忽略职业条件来放行。

候选使用实际法术条目的来源身份，保留 PHB／XPHB 区别。资料存在多个身份或不能唯一引用时，不自动任选。同 ID 的已存快照优先于新下载版本；资料不全只影响当前可选候选，不删除玩家已有选择。每次最多先显示 40 个未选候选，可按名称或来源搜索、继续展开；已选项始终保留显示。

## 选择、撤回与资源

只提供原始 `additionalSpells` 声明中的选择；可以少选，不自动替玩家决定。一个来源的同一组位置不能重复引用同一个法术，中文名和英文别名也不能绕过。同一法术来自不同来源时分别保留归属。旧重复选择不删除，暂停该组授予并显示修正提示。

选择通过已有来源法术执行器生效，继续使用原权限、保存、资源及休息所有者。重复刷新、更换选择、停用来源及恢复来源均不补发已消耗次数。固定数量、各自次数与共享次数沿用原机制；原本要求玩家确认次数归属的情况仍须确认。冻结来源中有一处须先作该选择，不能把未确认状态冒充已经提供法术选择。
