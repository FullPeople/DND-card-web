# 191：各发布端统一国内站改进

国内单机、GitHub Pages、Windows 单机下载包及 Suite-dev 集成网页使用同一套紧凑工具栏、等比平滑 Logo 和按 Wiki 实际可用宽度自动切换的列表/正文双栏。桌面顶栏 36 px，角色卡工具栏 28 px；枭熊角色标签栏缩至 24 px。底部保存状态不再占高度，真实错误与恢复提示仍保留。纸卡内部和缩放算法不变。

所有本机网页的资料来源与单项禁用由网站工作区共用，沿用 190 的一次迁移与旧配置快照。条目前「跟随角色 / 2014 / 2024」继续独立。新本机工作区默认启用全部来源，旧手动选择保留。

枭熊继续使用原来的房间/场景规则文档和 DM 写权限，不把本机站点配置覆盖到房间。新房间的默认配置增加 `autoSourceDefaults` 策略：客户端从当前资料目录推导未处理的新来源，无需玩家后台写设置；DM 调整时保存完整来源快照，已经取消的资料不会重新启用。已有房间未声明该策略时不改其来源选择。没有改动同步传输、角色状态或资源写入流程。

本轮发布范围：Suite-dev 1.0.191-dev、standalone-1.0.191、GitHub Pages 及 DND-Card-Standalone-191.zip。稳定旧版仍为独立产品，原公告保留；未发布 Buff 包和已撤回的屏幕适配实验不进入本次构建。

验证覆盖来源作用域/迁移、DM/玩家权限、双向分隔/阅读位置、角色切换、源码隔离、离线保存及既有同步/库存/法术交互回归。对应浏览器测试使用原创夹具；正式枭熊房间多人测试不在这份自动化结果中冒充完成。
