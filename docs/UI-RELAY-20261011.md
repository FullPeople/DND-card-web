`src/ui/App.tsx` 等受审消费者模块的散列已变，`vite build`、`vite dev` 与 `verify:automation-runtime` 会以 `Runtime coverage is stale for current consumer code` 失败，直到 Data 仓库 producer 对本分支最终提交重新审计。本会话对 `FullPeople/dnd5e-automation-data` 的访问被拒绝，以下步骤未执行：

```bash

  "<本分支最终提交的干净 Web checkout>" "<原公共缓存目录>" \
```
