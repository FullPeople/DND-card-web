# 普通多职业法术位修正候选

当前线上仍为角色卡／卡库 311。本候选只修正普通法术位计算，特殊法术位、统一休息和子职学习规则继续在独立工作树开发；本候选没有增加整条规则完成或验收数。

## 玩家问题与修正

旧计算用全部职业数量决定半施法、三分之一施法的取整，并仅在角色只有一个职业时读取该职业的真实法术位表。因此，2014 圣武士／游侠五级加入一级非施法职业后，二环位可能消失；奥法骑士／诡术师及加入契约施法职业的组合也会偏离自身法术位表。

修正只统计当前已经获得普通施法的职业。只有一个普通施法职业时，仍使用其真实来源表；有多个普通施法职业时，保留两版各自的多职业取整。契约位独立计算，所有职业继续计入生命骰。手工和锁定法术位的归属保护、已消耗次数及镜像同步保持原入口。

规则依据为官方 [2014 多职业规则](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/customization-options) 和 [2024 创建角色规则](https://www.dndbeyond.com/sources/dnd/br-2024/creating-a-character)，数量逐级对照原固定输入中的职业／子职表，不按职业显示名分支。
