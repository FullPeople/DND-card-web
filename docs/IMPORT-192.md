# 枭熊完整备份导入修复

根因：导入完整备份及枭熊 JSON 都沿用本机 `persist`，而房间角色簿由宿主目录管理，因此出现本机保存成功但房间没有新卡的假成功。

枭熊模式下改用既有 `createCard` 命令，与新增空白卡共用创建与切换流程。宿主按原权限保存完整原生快照及枭熊投影，写入房间/场景目录后确认；确认前不提示成功。失败保持导入窗口并显示错误，不产生隐藏本机副本。并发创建通过同步锁避免重复提交。单机导入分支及页面布局不变。

针对性验证包括玩家在没有选中棋子时导入完整备份、DM 粘贴枭熊 JSON、创建确认前无成功提示、导入后角色簿与卡片显示、属性/生命/资源内容保留、宿主拒绝及断线不误报成功。使用真实网页和受控宿主消息，不冒充真实多人房间验收。

本次快速部署仅替换 Suite-dev 的 workbench 前端和对应源码，宿主插件版本保持 1.0.191-dev；不修改传输中继、纸卡布局或稳定版。
