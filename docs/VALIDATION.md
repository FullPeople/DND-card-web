## 验收中修复的具体问题

- 最后一项选择完成时控件马上消失：改为保留选中的技能与属性选择，避免焦点丢失。
- 原枭熊字段映射不正确：按现有 schema 0.3 改为 `core_stats`、技能数组、分组特性、`spellcasting` 和 `inventory`。
- 只读取亚种族导致丢失父种族属性：补入可确定的继承；复杂继承明确提示人工复核。
- 升级/降级或删除上级条目后，旧选项仍可能提供效果：保留记录并暂停不再符合要求的效果。
- 离线网页有缓存仍无法加载脚本：Vite 静态响应含 `Vary: Origin`，预缓存与模块请求不同导致未命中；只对已知、固定构建资源忽略 Vary 匹配。已加入生产离线回归。
- 主编辑页关闭后只读页有时仍保留只读状态：等待浏览器释放写锁后重新读取最新文档并自动接手。
