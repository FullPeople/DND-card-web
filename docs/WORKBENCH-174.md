# Full Suite-dev 1.0.174 · 库存、资源与怪物卡精修

## 行为

- 同来源、规则快照、名称、重量和权限相同的物品，新增或拖到已有物品时合并数量；装备/同调只是显示引用，合并保留引用。跨背包转移、拆分、合并、撤销使用同一事务模型，真正不同的条目不会合并。
- 物品描边按绘图层自身尺寸绘制，网格、列表、仓库标题与切角背景共用边界；文字留出边距。拿起时保留源格子的完整排版，物品名不再被通用预览样式居中。
- 重排只按格子位置变化执行动画，回执不重复启动。装备/同调落点为实际气泡，物品格连续缩小并转为气泡，不隐藏整栏；金币同样可加入引用区，不改变计算。
- 快捷栏标题和空白处不再打开整理弹窗。各项投骰、资源编辑和拖拽仍可使用。
- 锁定图标使用红色；角色和怪物卡解锁为白色，配深底确保辨识。
- 怪物复用角色卡的 A4 外框、缩放和右侧标签，资料与背包分开；不启用纸卡状态特效。保留画布血条组件，开发版不再打开旧悬浮生命编辑器。
- 总览和怪物共用生命值、临时生命、盾牌 AC 和锁图标组件，盾牌在左。总览只收录场景中的绑定角色和有已确认玩家 owner 的怪物，DM 的 NPC 不进入玩家怪物列表；已确认的 owner 角色类型保留供离线时识别。
- 每项资源有淡色底，次数模式只有圆点，数值与进度条均支持输入。编辑弹窗点外部取消；错误使用带复制诊断的 toast，不挤压资源排版。
- 资源和生命输入立即响应，连续修改按对应资源/角色队列提交，不禁用操作。冲突检查、权限检查和撤销保持有效。
- 资源及背包增减重新发送场内通知和原音效；提示层有送达确认、去重和丢失后重建。锁定资料在不可查看端隐去名称/数值，DM 不提示消息开关继续生效。
- 网页、骰盘、设置、音乐和三龙牌界面采用 #50525B 石墨基准色；增加命名色盘、十六进制输入和即时示例，保留个人颜色及各类语义色。

## 根因

总览以角色 ID 提交锁定，而宿主的无选择 key 操作白名单遗漏 lock；现沿用目标角色的权限验证。库存预览的通用 strong 样式覆盖了实际格子字体，SVG 测量边界又与背景不同。落入装备栏时旧动画隐藏整个目标框，库存回执还会依据动画中的位置重新运行 FLIP。以上均在实际路径修正。

资源输入原来在每次等待确认时禁用，连点与旧回执容易造成回跳；现在保留本地意图并串行提交。场内提示层的 toastOpen 布尔值并不代表 iframe 仍然存在，现在以确认消息判断送达，必要时重建。

## 验证边界

单元、库存事务、同步合并、真实浏览器 UI 及 SDK 边界模拟结果记录在 STATUS 和 Suite workbench-test-output。模拟覆盖慢写入、连续编辑、权限、撤销、提示层关闭/重建、源样式与落点、A4 尺寸和玩家 owner 过滤。真实枭熊房间与实体平板尚未实测；不把构建成功当成真人实机验收。

最终本地检查：57 单元；库存事务、8 组合并和 9 组库存同步；47 + 89 + 77 项工作台模拟全部通过。纸卡/背包 6 项视觉交互通过，库存 3 项在最终动画调整后再次通过。47 项新回归包括实际通知页去重、隐私显示、音效广播和旧 HP popover 停用。
