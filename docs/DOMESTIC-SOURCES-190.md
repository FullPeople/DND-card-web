# 国内单机站资料来源共享

仅适用于 `build:domestic` 与 `https://obr.dnd.center/card/`。

右上角「规则与扩展 → 资料来源」的扩展勾选、资料内单项禁用，保存在本机工作区的 `siteSources`，由所有角色共同使用。未勾选来源不进入 Wiki；开启来源内单独禁用的条目仍可搜索并显示删除线。角色卡按同一来源配置判断其已选条目和拖入许可。

条目列表前的「跟随角色 / 2014 / 2024 / 所有版本」及每个分类的筛选记忆完全保留。角色的基础版本、可选规则、特许、内容与数值继续独立。资料来源配置码只导入来源设置和来源显示偏好，不覆盖当前角色版本或可选规则。

首次迁移使用当前角色的来源设置；原来每张卡的来源选择保存在 `legacySourceProfiles` 以便恢复。新工作区默认开启全部来源，后续加载的新来源也默认开启；手动关闭的来源不会因刷新、新建、复制或导入角色而重新打开。旧配置没有自动开启策略时，沿用旧策略。

资料来源操作进入独立撤销动作。角色撤销以当前网站来源设置为准，避免恢复旧角色快照时顺带还原网站设置。自定义扩展包安装、移除与来源启用沿用同一工作区作用域。

验证：124 核心测试通过；4 个本轮浏览器流程覆盖切卡、新建、导入、刷新、单项禁用/搜索、撤销/重做、旧数据迁移、配置码与角色规则隔离。另复查国内 Wiki 双栏/纵向布局、分隔拖动/持久化、默认来源与手动取消、手机界面及 A4 可用高度。

发布使用独立克隆构建，仅更新国内 `/card/`。保留 Suite 稳定版、开发版、GitHub Pages、旧下载 ZIP、中继与 nginx；公开对应源码包。来源共享范围是此浏览器的网站工作区，不引入联机配置服务。
