## 根因与修复

旧版20秒看门狗将尚在下载的情况显示为未收到启动信号。实际复现中，程序最终仍能打开，关键耗时是网络下载及主入口之后才开始的主体依赖请求；不是已证明的浏览器版本过旧或持续主线程死循环。初始单机最长主线程任务约276毫秒。

227提前并行下载主体及对应样式，拼音词库与部分配置面板按需加载；大型图标延后到卡面出现后，支持图片使用低优先级。慢加载显示阶段与等待时间，真正的文件/脚本失败保留详情与重试。已安装离线壳时，网页网络响应超过1.5秒便使用缓存，后台请求继续。

226公网复验另发现样式预加载与后续加载的credentials模式不同，浏览器拒绝复用。227统一crossOrigin；新增每份样式仅一次请求的回归在226失败、227通过。最终公网四次加载各5个样式请求，无重复下载和credentials告警。
