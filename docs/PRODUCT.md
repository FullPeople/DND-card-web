最新本地约定（覆盖下文历史版本的自动填写检查）：角色卡采用手动编辑；不生成技能、专长、法术数量和属性成长选择要求，右侧只做资料查阅。技能/豁免可自由勾选，装备训练可手填；保留基础计算、来源开关和声明式效果。加入背景、种族、职业/子职时，根据资料关联带入固定特性/专长，气泡逐项出现并平滑让位。手动移走的自动特性持久记录，刷新不会恢复；拖出身份格会撤回该条目及其关联特性，可撤销。

单职业时职业在上、子职在下；第二职业拖入后合并为大格，移除后恢复。身份内容居中，不设 ×；新增时高光扫过内容、灰色标题带与边框。拖拽小卡的抓取点固定在鼠标处。生命值为「当前 / 上限、临时」，上限直接可编辑，移除补满及单独的手动上限入口。

## 已确认

完整网页端先行，Godot 不再作为运行时。未来 C++ 客户端复用同一套网页界面和规则是推荐方案，完全原生 UI 尚未确认。

左侧沿用原角色卡和 StyleBox；右侧 Wiki 改善阅读、搜索、筛选、往返定位和拖拽。避免模板式大留白、装饰卡片堆叠和无意义动效。

角色卡本身引导填写：缺专长、特性、技能或内部选择时，在对应位置显示来源与数量；点击可定位右侧候选；允许自由顺序和人工裁定。保持来源追溯、撤销和保存恢复。

支持 2014 与 2024。资料源为 https://5e.kiwee.top。优先独立角色与 DM 导出；Excel 适配与 C++ 客户端后置。枭熊 JSON 文件交换在网页范围内。

## 数据与规则

- 资源采用来源、类型和上下文身份；翻译名不作为唯一键。角色保存所选条目快照。
- 基础输入、已选内容、填写需求、计算结果与游戏中的资源状态分离。
- 基础规则、扩展书籍和可选规则分别配置；支持批量启停、配置导入导出与自定义规则包。
- 禁用不删除角色内容；受限条目不继续暗中提供效果，例外须有说明。
- 自定义包必须有命名空间、版本、适配版本、依赖和冲突；校验成功后整体安装。声明式规则不执行任意代码。
- 复杂条目允许以文本和人工裁定处理，必须明确标注覆盖，不能声称所有 D&D 条目均已自动计算。

## 技术

TypeScript + React + Vite。规则核心不依赖界面。浏览器存储由平台适配器承担，未来 C++ 文件接口替换适配器。程序源码公开，v0.1.4 起采用项目非商用共享许可；分发或对外服务须公开完整衍生源码并沿用许可，商用另授权。资料与程序许可分开。
