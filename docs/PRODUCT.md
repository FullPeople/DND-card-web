# 产品约定

## 已确认

完整网页端先行，Godot 不再作为运行时。未来 C++ 客户端复用同一套网页界面和规则是推荐方案，完全原生 UI 尚未确认。

左侧沿用原角色卡和 StyleBox；右侧 Wiki 改善阅读、搜索、筛选、往返定位和拖拽。避免模板式大留白、装饰卡片堆叠和无意义动效。

角色卡本身引导填写：缺专长、特性、技能或内部选择时，在对应位置显示来源与数量；点击可定位右侧候选；允许自由顺序和人工裁定。保持来源追溯、撤销和保存恢复。

支持 2014 与 2024。资料源为 https://5e.kiwee.top。优先独立角色与 DM 导出；Excel 适配、付费服务和在线绑定同步后置。枭熊 JSON 文件交换在网页范围内。

## 数据与规则

- 资源采用来源、类型和上下文身份；翻译名不作为唯一键。角色保存所选条目快照。
- 基础输入、已选内容、填写需求、计算结果与游戏中的资源状态分离。
- 基础规则、扩展书籍和可选规则分别配置；支持批量启停、配置导入导出与自定义规则包。
- 禁用不删除角色内容；受限条目不继续暗中提供效果，例外须有说明。
- 自定义包必须有命名空间、版本、适配版本、依赖和冲突；校验成功后整体安装。声明式规则不执行任意代码。
- 复杂条目允许以文本和人工裁定处理，必须明确标注覆盖，不能声称所有 D&D 条目均已自动计算。

## 技术

TypeScript + React + Vite。规则核心不依赖界面。浏览器存储由平台适配器承担，未来 C++ 文件接口替换适配器。程序代码开源，资料与程序许可分开。

## 参考资产

Godot 左侧的 theme.tres、dnd_5e_card.tscn 和 card_items 场景用于视觉还原。数字栏的深灰外框、浅灰内容、底部灰标题和背景图形为重要特征。网页纸张固定为 A4 的 210:297 比例，整体自动适配可用窗口；纸张和左侧工作区不接受滚轮滚动，只有各个内容区域独立滚动。

2026-09-21 补充的界面约定：左下方横向折页标签为「主要 / 特性 / 背景 / 法术 / 背包」。主要页概述人物，后四页在相同纸张尺寸内提供完整正文和编辑；子职合并在职业名称旁。右侧上方是紧凑分类、筛选与候选列表，下方是当前条目，窄窗口也同时保留。规则关键词支持悬停和键盘焦点预览，显示原条目与版本来源；没有资料时明确说明。拖拽使用专用词条预览，只有兼容的填写区域出现呼吸和悬停动效，拖过页签可展开对应纸页。

音乐板的 UTF-8 边界、明确错误与保存恢复，以及桌面骰子的主题包导入事务和数据/呈现分离为工程参考。旧项目通过的测试不替代新产品验收。
