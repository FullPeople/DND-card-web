## 六项结果

1. Tooltip 自身能滚时先滚正文；到边或正文较短时，把余量交给指针下方的实际阅读区域。保留模态边界、横向表格和 Ctrl 手势，也修复嵌套固定说明被重建的问题。
2. 云端按钮左侧新增角色卡独立调色盘，提供六套示例。网页调色盘只管网页；旧混合配色文件按所打开的范围导入，分别保留撤销、重做、预览、保存和权限保护。
3. 待选特性提示放在所属标题右侧，虚线只围小型计数。桌面对应提示外框面积减少 53.7%，特性计数虚线面积减少 78.7%；保留完整名称、选择流程和窄屏操作。
4. 切卡不再播放额外的约 180 毫秒淡入；未聚焦数字框不再复制状态造成第二次提交；特性首次动画测量延到绘制之后，明确编辑仍保留动画。原 303 的计算缓存、导航保存、冲突及草稿保护不变。
5. 两份中文资料主镜像仍返回 404，已核对同语言备用部署源的精确来源身份、路径及可读正文。仅在主镜像确实 404 且没有有效旧缓存时恢复，不使用英文替代、不建立重复资料身份。真实浏览器完成两次 404 → 200 和正文规范化，原镜像恢复后仍可正常刷新。
6. “贤者三级”尚未复现。已检查四组职业候选的 32 种组合、160 个等级阶段及 39 条三级引用；另发现实际名为“贤者”的 2024 法师子职，完成共九组宽屏／A4／窄屏、升级、选择、展开和刷新页面检查。均未复现缺失；不能认定其就是玩家目标，也没有按职业名称编造修复。
