## 构建与数据边界

正式站使用 `vite.standalone-cloud.config.ts`、`vite.library-cloud.config.ts` 的显式生产配置；只有这两个目标启用经过测试的 QQ／私人卡库。默认构建的暂停开关保留，用于其他尚未获准开放的目标。后续正式更新必须沿用生产配置，不能直接用仍暂停的默认包替换线上版本。

正式前端沿用原浏览器存储命名空间、`/api/` 和原 QQ 回调。后台保留 `/var/lib/dnd-card-cloud/cards.sqlite` 的原文件身份，实际文件位于 `/var/lib/private/dnd-card-cloud/cards.sqlite`。没有复制测试 SQLite、测试 Cookie、测试角色或测试浏览器存档。部署包没有私有角色备份、环境文件或数据库。

登录和目录读取独立于当前卡面；卡片正文按需读取，已打开卡的计算缓存复用。切卡只保存选择，不重写整册。保存合并调度、修订冲突、未知写入回执和本机草稿保护沿用已在隔离测试版验证的实现。缺失存储区只补齐；缺人物正文时阻止空白覆盖。
