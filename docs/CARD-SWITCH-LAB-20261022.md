# 独立切卡实验与局部性能候选

本轮以正式 305 的运行源码 `d4f8200` 及文档基线 `ab68849` 为起点，在独立工作树调查。正式网站、卡库、Wiki、插件及后台尚未加入这些候选。

## 实验边界

独立入口计划为 `/card-switch-lab/`，在正式 `/card/` 的离线缓存作用域外。页面从原生 DOM 开始，按需加载简单 React 卡面、真实 Overview／PaperFrame 和规则计算。初始 JS 约 12.7 kB、CSS 约 3.1 kB；初始层不下载 React、规则计算、真实卡面样式或 Wiki。

第三至第五层复用真实卡面组件与计算，不加载 App、云端或来源提供器。显示模式使用内存存储，不写正式偏好；本机 JSON 经原校验器检查后只放在页内存，刷新清除。CSP 禁止所有连接、框架和表单提交。导出只有计数与时间，不含角色名、身份、原文或卡片正文。

五层对照：

1. 原生 DOM，提前保留全部卡面。
2. 简单 React，切换时渲染。
3. 真实卡面，切换时求值与渲染。
4. 真实卡面，缓存求值，切换时仍渲染。
5. 真实卡面，提前计算并保留 DOM；切换只改变可见层与 inert 状态。

第五层是独立实验，不表示正式 App 已采用多卡面保留架构；正式 App 的共享上下文、输入、权限、保存和导出仍须另外验证。没有通过忽略旧回调、丢弃保存或强制整张卡重挂载来伪造命中。

## 当前证据

2026-10-22，实际 Edge 生产构建的 8 项浏览器流程通过，包含五种模式、A4、原特效、淡入对照、导入失败不改变当前卡、偏好保留，以及已有三张私有卡的只读副本对照。三卡原始内容完整相同，未连接云端；私有输入没有加入仓库。

同一进程的原创 80 特性示例中，第四层即使求值为零，12 次切换仍有 12 次卡面根提交与 1,920 个新增 DOM 节点，提交中位约 20.7 ms。第五层为零求值、零卡面根提交、零 DOM 增删，提交中位约 0.4 ms。三张既有卡副本按第四→第五→第五→第四顺序复测，全部原始结果保留；其中一组第四层提交中位约 29.45 ms、最大 68.7 ms，第五层中位约 0.3 ms、最大 1.0 ms。

这些是当前设备上界面提交的受控观测。“下一帧”包含浏览器调度，不能当作精确像素绘制时间或所有设备零延迟保证。表中卡面提交只统计根组件，DOM 增删另行统计。早先采用生产包 React Profiler 的三组检查失败，原因是生产包不提供该回调；已改为卡面根布局提交计数，重新执行全部检查，没有把旧零计数算作通过。

## 已确认的闪烁与候选

原 PaperFrame 用角色身份和页名共同触发 180 ms、0.78→1 的淡入，缓存命中也会播放。候选保留同卡切页动画，换卡立即显示并取消旧卡未结束的淡入。缩放重置在值未变化时保留原状态对象，避免非 A4 的空状态更新；相同 transform 不重复写入。9 条动画转换单元和另外 32 条相关检查通过，真实卡面实验没有空白帧或错误卡面帧。

数字框的绘制前草稿同步、特性行跨卡同步布局读取正在独立候选中验证。它们尚未计入以上实验的改进结果。

完整测量与原始失败保存在私有控制目录 `next-six-20261022/`。正式发布、最终整合 CI 和用户设备验收分别记录，不能用实验页通过替代。
