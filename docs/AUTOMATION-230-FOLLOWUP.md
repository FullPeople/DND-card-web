## 失败与修正记录

1. 临时 Playwright 配置最初按配置目录寻找 Vite，服务器未启动；显式设置 `webServer.cwd` 后恢复。这是测试配置错误。
2. 新交互首轮暴露待选气泡与独立折叠按钮使用同一个“折叠”标签，且名称实际打开选择；已改为符合行为的“选择”。
3. 第二轮暴露已完成气泡被资料 `Reference.commit` 接管，不能展开；修正后完整交互通过。
4. 本机追加性能测试时错误地与完整组并发共用 outputDir，清理了对方 trace 文件，导致 ENOENT；完整组的最后自定义宏场景和大库场景归档受影响。保留故障材料后改为串行；大库单跑通过，完整 18 场景随后 13 通过 / 5 跳过 / 0 失败。没有把归档错误计为产品通过，也未忽略最终失败。
5. 本组最初 tsc 曾撞到资源同事在途的 `ResourceModuleFace.tsx` 类型错误；由资源同事收口后，最终共享源码 tsc 通过。
