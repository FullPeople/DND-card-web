## 认证与边界

`FeaturePanel.tsx` 属于原运行账本绑定的消费文件，改动后普通 Vite 的旧账本检查正确报过期。本轮没有更新或放宽账本、锁、检查器，不能沿用 305 的旧认证宣称新候选已发布或完成完整回放。

为完成 UI 检查，专用本地服务器保留实际 React 与单机模块边界；它把进度清单明确设为不可用，不生成发布证据。两个专项服务器各用工作树内独立缓存，避免共享 `node_modules` 的预打包产物相互覆盖。Tooltip 的单独夹具同样直接挂载实际组件，不提供发布认证。最终整合仍须重新配对准确消费源码的账本、全量验证和正式构建。

这些是原创隔离卡和浏览器触摸模拟，不替代玩家原卡、实体手机或真实枭熊房间验收。
