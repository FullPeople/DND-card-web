## 最新产品约定

- 法术页只保留“预备法术”与按施法模型显示的“已知法术”，取消第三个“固定 / 次数法术”栏目。
- 预备栏纵向排列：各职业戏法格 → 按种族/特性来源分组的赠送法术 → 普通预备格。随等级选择的职业法术同样放在此栏。
- 法师、牧师、德鲁伊及用户确认纳入的奇械师显示已知栏。实现读取法术书、每日准备、戏法成长等结构字段，不按中文职业名分支；无职业、资料不全的手动施法者及显式手动每日预备保留可编辑列表，避免藏起既有法术。
- 法师法术书中的有环法术仍需记录；牧师/德鲁伊等按其结构化法表提供候选。职业戏法候选支持法术书模型、奇械师成长模型或明确声明的长休替换机制；候选不全量写入角色，只有实际选择时才保存。
- 已知栏保留已选条目，用“已选 / 已预备”标记，方便核对；不再准备后就从列表消失。戏法格与普通预备格分开计数。
- 赠送法术格略高，用“免费 1/1 · 长休”“共用 2/2”“已预备 · 法术位”等短标记；点击角标打开施放详情，处理消费、升环、恢复和来源属性/DC。已用次数不因布局、刷新、来源停用或更换格子而恢复。
- 来源授予仍不可单独拖出或从菜单删除。历史手动固定/次数记录继续保留在底层兼容字段，展示到来源分组；没有强制重写原始数据或清空资源。
- 来源信息、次数归属或格式未明确时，在预备栏折叠提示需要核对，并提示自动化设置入口。

## 已修正的判定

1. `spellUsesPreparation` 只按具体法术实例判断来源/额外施法，不用“相同条目已有次数副本”阻断普通副本。
2. 普通预备清单排除戏法、赠送与随等级选择法术，避免旧记录产生看不见的占位。旧的普通法术与超限记录保留并提示。
3. 满格时拖到指定已占位置可替换；被换下的法术仍留在已知栏。未指定位置且满格仍拒绝，不悄悄丢弃另一项。
4. 戏法按职业保存选择；兼容旧卡的默认分组是只读投影。换掉的戏法仍已知，但总览及旧格式导出的可用戏法不再包含它。源赠送戏法不进入普通戏法配额。
5. 已经补过职业资料的旧导入卡，可以从原来关联的同一身份补齐后来新增支持的戏法成长字段；不覆盖已有值、不重新匹配同名不同来源。
6. 无已知栏的随等级选择职业，已选法术直接展示在预备栏；保留职业数量空格和查阅入口。
