## 原因与范围

历史内容面使用 66% 不透明度；组件调色样式后来同时给 `.cell-surface` 和 `.cell-content` 填入实色，覆盖原透明效果。浏览器已确认旧版实际背景不透明，已有水印被内容底色遮住。

源码仅改 `src/ui/appearance.css`：外层内容面按原比例混合透明色，内层正文保持透明；技能区保留独立组件配色，并使该底色半透明。技能区位于属性区内部，二者会按 CSS 正常叠色，不宣称每个像素均为单层 66%。隐藏头像框继续使用透明背景。标题、边框、文字颜色、布局、规则、保存及缓存代码没有改动；不通过整块 opacity 淡化文字。
