# 国内站 Wiki 分屏、Logo 与扩展默认值

2026-09-24，继续限定国内单机站。发布标识 standalone-1.0.187-domestic.2；使用 `npm run build:domestic`。

- Logo 移除 `image-rendering: pixelated`，使用平滑等比缩小，禁止 flex 挤压。保留原 PNG 和顶部 36px 高度，不重新生成图案。
- Wiki 自身宽度达到 1040px 时：左列包含搜索、分类、筛选和条目，右列独立滚动正文。宽度取自 ResizeObserver，因此拖动角色卡/Wiki 分隔线也会切换布局。
- 窄于 1040px 保留上下列表/正文。两种模式共享同一批 DOM，不因布局切换重建当前条目。宽度与高度比例分别保存在本机；支持拖拽、方向键、Home/End、Esc 取消。
- 新建本地角色默认开启所有已载入来源，后来载入的来源继续开启；`autoSourceDefaults` 记录已处理来源，手动取消的来源不会在刷新时复活。已有角色、导入角色、复制角色保留原来的规则配置。点击「仅基础规则」或「全部禁用」会停止自动开启新来源。版本和单条禁用规则仍生效。
- 普通 standalone 构建和 Suite 不启用本轮布局及新角色默认值。

验证：120 项核心测试；5 项本轮浏览器检查（宽窄切换与阅读位置、双向分隔与持久化、默认来源与手动关闭、手机布局、普通构建隔离）；5 项既有触摸/桌面交互回归通过。真实资料读取 29,469 条，抽样吟游诗人职业正文、表格与目录的双栏排版。保持 188 的 A4 68px 高度收益。

发布仅替换国内 card/，Suite 稳定版、开发版、旧 ZIP 下载和中继保持原样。源码包含在本站 source.zip；GitHub Pages 未发布。
