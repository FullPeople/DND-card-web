# 本地 303：导入时准备首次卡面（待人工验收）

本轮只处理第 0 步新增的首次切卡停顿，没有合并其他功能，也没有部署、推送、改线上数据库或操作正式账号角色。原 303 对照页保持 `http://127.0.0.1:5411/card/`；本地候选为 `http://127.0.0.1:5413/card/`。

## 改动与边界

JSON 单张、批量及 Excel 的本机导入，先完成原 303 的卡面计算、选择解析、迁移提醒和首次协调核对，再加入角色簿。读视图与正常卡面使用同一份缓存。协调仍调用原有职业、资源、施法恢复及来源法术函数；只有实际完成且没有变化的检查可以复用。准备可取消，来源上下文变化时重做，权限失效时停止写入。

导入准备会增加导入阶段的工作量，逐阶段让出界面，显示进度。页面重开或资料上下文变化后，在空闲时准备本机已载入的卡片；发现旧卡需要实际更新时，后台预热只检查，不自动批量改写旧卡。房间及其他构建继续使用原有路径。

存储、轻量选卡写入、保存队列、冲突与未知回执保护没有删除。规则核心源码没有修改，既有浏览器存储命名空间保持。
