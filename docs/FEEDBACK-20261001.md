## 旧卡同步行为

1. 背景、职业、种族、子职与背包逐项匹配；同名多个来源需用户选择，2014/2024 身份分开，未启用来源不能成为目标。
2. 根据已确认的资料声明核对来源气泡，替换对应旧记录或新建；取消的声明会记为主动删除，刷新不会补回。
3. 额外气泡可重新归入专长、特性、法术或背包，保留对应的正确分类和来源关系。
4. 未匹配的气泡由玩家逐项选择保留或仅从副本删除。
5. 核对法术、装备训练、语言；保留原有技能/豁免熟练与专精。已知旧格式的语言/工具字段可从原始快照恢复，显式的空原生字段不被覆盖。
6. 最后显示替换、增删、数值与资源差异，由玩家创建同步副本。原卡完整保留，保存失败可重试；未知远端创建结果继续禁止重复创建。

数量、装备/同调、单武器属性选择、预备法术 ID 与现有资源余量保留；新资源从 0 开始，不重新发放起始金钱/装备。手动数值修正保留并提示核对。主动保留的自定义资料存独立确认标记，不能伪装成官方来源，也不会在同一版本每次加载反复报警。

真实房间只读检查确认一张卡的 `expertise` 含 `save:cha:false`、`save:con:false`，被技能字段验证拒绝。根因是旧版取消豁免熟练时也向专精写入 false。现在修复写入源头，并仅规范化合法豁免键的空 false；true、未知键与其余非法值仍拒绝。原记录读取时不自动写回，备份导入也支持此兼容。加载失败时显示明确错误，不再留着上一个角色的纸卡。
