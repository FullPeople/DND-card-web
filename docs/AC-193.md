# AC adjustment repair

The character overview now uses the same right-side manual adjustment control as initiative, speed and passive perception. The computed AC stays read-only. The offset follows recalculation and is retained in native backups, Owlbear saves, and undo/redo.

Legacy scene AC totals subtract the retained offset before becoming absolute base overrides. Suite runtime-authority applies the same rule so receiving an AC total never adds the offset twice.

Validation: 29 targeted core tests; two browser cases covering persistence, undo/redo, edit mode and a simulated Owlbear delta/ACK; Suite runtime regression tests including positive/negative AC offsets and repeated scene echoes. Type checks, integrated build and standalone build pass. The browser host is simulated, not a real multiplayer-room acceptance test.
