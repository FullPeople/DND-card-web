本候选基于 `ab68849`（正式 305 后的文档基线）。只调整配色入口、文件和显示编辑；未推送、合并或部署，也未写入玩家原云端卡。共享 `AI_HANDOFF.md`、`STATUS.md` 和最终规则来源绑定由整合分支统一维护。

## 行为

- 卡片右上角的调色盘位于原云端／锁定按钮左侧，只编辑当前角色。网页调色盘只保留基础界面与 Wiki。
- 提供原色灰阶、暖纸棕墨、林地苔绿、青瓷蓝灰、暮色紫灰、夜航蓝墨六个整卡示例。示例会替换当前卡的组件配色，可继续逐项改色和撤回。
- 既有 `palette`、`componentPalette` 及完整角色 JSON 兼容保留；组件底色仍以原有 66% 透明度显示。没有更改规则值、生命或资源余额。
- 角色卡配色另存为 `dnd-character-palette`，网页配色沿用 `dnd-card-palette`。旧混合文件从网页入口只读取网页域，从角色卡入口只读取角色卡域；另一域不参与本次应用。
- 导入、整组恢复、配色撤回和重做均通过一个明确的显示编辑同时提交两组颜色，形成一次角色操作和一次保存。已有保存失败、草稿恢复及冲突处理继续由原保存链负责。
- 选色预览直接使用显示变量，未松手前不写存档；Esc 取消。关闭或切卡后才完成的文件选择不会修改任何角色。
- 编辑抽屉按需加载，关闭时卸载所有颜色字段和字段监听；历史只保留颜色快照。网页初始配色与 CSS 仍随轻量按钮入口加载，不等待打开抽屉。
