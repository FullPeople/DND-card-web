# 来源法术选择生命周期修复

## 已证缺陷与范围

在 Web 主线 `3c67c29d20817ecd23d5987ece3b98a39a046e33` 上，原创角色通过选择格取消或替换带法术的专长、或降低授予职业等级后，保存的原生角色会在重读时抛出“固定与次数法术设置无效”。新增首批六个回归在改动前为五失败、一通过；直接调用条目删除的对照用例本来通过。

选择格清空只改 `answers`，随后的 `syncChoiceContent` 原本直接过滤选择树；职业选择则由 `parkClassChoiceGrant` 将树移至 `classChoiceArchive`。两者均可能保留 `spellSettings.special`，但读取校验只查当前 `selections`。`App.edit` 与枭熊保存入口没有运行这一原生读取校验，因此错误状态可能先被保存，随后在读取边界被拒绝。272 配套 Web `0b22594` 与上述主线的相关生命周期文件相同。

此处用原创软件夹具重现同类错误，未取得或修改玩家的实际角色文件，也未确认玩家使用的是选择格删除还是普通条目删除。不能将这一结果表述为真实玩家文件已修复。

## 修复

- 真正取消的普通内容选择使用既有 `removeSelection` 生命周期，清理其法术配置与无其他持有者的计数，保留消耗账本、独立法术副本和其他来源的授予。
- 已通过完整结构和身份校验的职业选择档案继续拥有法术设置。读取保留其原 ID、配置、余量、嵌套树及来源关系，不重新激活档案或补充资源。
- 法术可用性要求条目仍在当前选择集合。归档的普通手工次数法术也不能通过遗留资源入口使用。
- 归档的资源付费法术使用保留的祖先快照验证归属，跨职业资源引用仍被拒绝。
- 无对应当前或已验证归档法术的孤立配置仍拒绝；模式、次数上限、恢复方式、手动来源及其他既有校验不放宽。

## 验证与边界

最初六例修复后全部通过。扩展回归覆盖手工及来源法术归档、保存往返、还原后的余量、删除原职业、独立来源副本，以及非法模式、零上限、非法恢复、断裂档案、缺失条目和跨职业资源引用。类型检查通过。

首次完整单元运行：1,275 通过、91 个既有条件跳过、17 个失败。失败属于运行审计报告仍绑定旧消费者字节的门禁；没有放宽或跳过。新的权威 Data 报告、最终完整单元、生产构建和浏览器保存/重读验证仍需完成，完成后补充实际结果。

现有卡如果完整法术树仍在有效 `classChoiceArchive`，兼容校验可以直接读取它，无需删除其配置。如果法术条目已真正缺失，则需要保留原 JSON、恢复备份或逐项核对，不能将清空全部 `special` 作为通用无损恢复。此改动不自动写回任何玩家生产卡。
