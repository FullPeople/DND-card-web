# Tooltip 滚轮归属，本地候选

基线为 `ab68849`，运行代码与正式 305 的 `d4f8200` 相同。本轮仅提交隔离工作树候选，没有推送、合并或部署，也没有读取、导入或改写正式角色数据。

## 行为

说明正文或其中的横向表格仍有可滚范围时，先滚说明。短正文、顶部和底部把余下滚动量交给鼠标下方实际可见的阅读区域；不会依据最初链接的位置误滚另一栏。固定说明的透明遮罩也遵守这一规则。保留横向、斜向、Shift、行／页单位和 Ctrl 缩放手势。

下层内容继续遵守自身的滚动边界；明确模态框到边时不会穿透到背后页面，即使它没有额外的 CSS 滚动锁。多个固定说明之间也可依实际覆盖顺序承接滚动。

浏览器检查还复现了嵌套说明反复重建的问题：错误边界原先优先使用当前悬浮说明 ID，子说明出现时会重建已固定的父说明。现固定在第一张已固定说明，关闭整组后仍可重新打开和重试错误。
