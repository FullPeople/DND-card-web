# 单机云端角色标签切换

用户已用真实 QQ 在 Chrome 和 Codex 内置浏览器登录，并确认本人私人卡库很快显示。随后明确指出：卡顿来自角色卡上方的角色标签相互切换，尤其切回已打开的云端卡。本轮只处理独立云端测试入口；正式单机定稿和枭熊端不发布。

## 改动范围

- 已打开角色的来源投影、构建视图、可选项、迁移检查和派生数值，按不可变快照复用。缓存属于当前编辑器；规则目录、规则包、来源或房间上下文改变时重新建立。新编辑快照重新计算。普通暂停构建和枭熊路径不启用此缓存。
- 单纯切卡在首次内容持久化后，只写当前角色 ID。角色内容、头像和完整备份不再随每次切卡重写；内容修改继续使用完整快照事务。刷新从独立元数据恢复选中项，完整内容保存原子清除旧元数据。仍等待真实事务完成才显示保存成功，失败保留原失败状态。
- 已检查过的同一份角色快照，不因来回切换重复启动云端摘要和同步。首次查看和实际编辑仍检查，切离前的待存修改继续保存；权限、CSRF、修订冲突及不确定写入恢复不变。
- 顶部角色标签记录点击至布局提交、后续绘制帧的耗时，只写无身份信息的 DOM 属性，便于区分页面真实耗时与浏览器控制工具耗时。外观、触屏拖动和键盘切换保留。
- 同时保留上一轮本地 QQ 登录反馈：先显示保留档案／连接提示，记录准备耗时，并在用户准备点击时连接 QQ 域名。不能据此宣称偶发授权页长等待已修复。
