# 真实云端卡切回专项

仅更新独立 `/cloud-lab/` 测试前端，正式站、枭熊端、后台和人物数据库不在本次发布范围。

前次本人账号的实卡在主要页面两次切回，布局提交为 197.3／230 毫秒，两个绘制帧回调为 392.3／466.8 毫秒。这些是页内计时，浏览器控制接口的超时不计入。生命 1→2→1、刷新和整卡内容核对已验证；不能据此宣称性能完成。

本次候选让已经检查且无变化的不可变构建快照跳过整卡复制及职业、资源、法术同步。只缓存无变化的成功检查；实际编辑、规则目录／来源改变、新快照及失败均重新检查。只在独立云端单机配置启用，普通暂停构建和枭熊保留原路径。资料列表保留至多四份读取投影，完整依赖变化时重新筛选与排序。没有改变条目内容或显示样式。

真实卡的只读本机副本与原始 229 份资料输入组成 29,459 条目录，仅测试重复核对：旧路径 12 次各约 76–102 毫秒；候选只执行首次约 78 毫秒，后续复用。原始人物副本未变。这是 Node 计算检查，不是公网或整页性能。

新增输入提交／后续绘制和实际云端同步事务的独立 DOM 计时。同步计时从既有同步引擎开始到确认成功，不含 650 毫秒合并等待；失败或冲突不产生成功计时，不新增请求，不改变保存调度。

定向测试、完整规则回放、正常构建、确切提交 CI、本机画面和公网实卡复验继续记录。未提交证据位于 `.local-evidence/cloud-stage2/`；私人角色副本不得打入源码或发布包。
