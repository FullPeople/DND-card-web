# 首版规则覆盖

当前本地版本采用手动角色卡：不生成选项数量、法术数量、专长前提或属性成长问答，不提供“正在填写”状态。资料负责说明，玩家负责选择；只有明确来源关联、基础数值和声明式 effects 自动处理。此前发布版的选择检查不再是本地实现约定。

| 范围 | 自动处理 | 仍需玩家 / DM 核对 |
| --- | --- | --- |
| 版本与来源 | 2014/2024 独立身份、来源开关、旧版兼容、逐条特许 | 两版具体替代关系及团规 |
| 基础属性 | 手动输入、调整值、明确声明的 effects | 特殊上限、临时变化、投点过程 |
| 技能与豁免 | 固定熟练、基础豁免和熟练加值；玩家可逐项自由覆盖 | 专精、重复熟练的替代、条件性优势 |
| 职业成长 | 总等级；按资料关联及等级带入固定职业/子职特性 | 兼职资格、复杂子职/条目触发联动 |
| 专长 | 背景明确授予的专长；保留资料中的指定选项文字 | 专长、种族、施法等其他复杂前提 |
| 生命与护甲 | 首级满生命骰、以后固定平均值、每级至少1 HP；普通护甲/盾牌与敏捷 | 自掷生命值、无甲防御、魔法加值等特殊规则；使用人工修正 |
| 法术 | 资料分类、正文查阅、手动加入 | 复杂准备公式、额外法术来源、兼职/子职施法、仪式与施法条件 |
| 资源 | 当前/临时 HP、激励、自定义法术位及使用次数；手动消耗与恢复 | 休息时应恢复哪些资源，不自动补满 |
| 亚种族 | 简单父种族资料、移动速度、固定熟练和正文继承 | 复杂 `_copy`、模板实现和未适配的继承操作 |
| 起始装备 | 展示上游选择说明、手动拖入物品、穿戴、数量 | 起始财富选择、武器攻击、负重与魔法物品调谐 |
| 正文 | 常见条目、列表、表格、引用与来源修订 | 极少见渲染类型与复杂交叉引用可通过原站和原始数据核对 |
| 枭熊交换 | schema 0.3 的身份、属性、主数值、技能、特性、物品和法术 | 防御标签、武器攻击、复杂资源、准备状态等未完全映射；导出附说明 |

原生角色备份保留已选资料和填写记录。导入枭熊时保留原文件快照，并将不可重新推导的数值记录为显式修正。更换角色来源或升级后，应核对这些修正是否仍适用。

## 维护规则

新增关联适配必须验证添加、撤回、升级/降级及禁用来源，手动移除的特性不能在刷新时复生。不得重新引入按条目名分支的选择检查；无法解析的关联不伪造条目，仍可阅读来源正文并手动添加。
