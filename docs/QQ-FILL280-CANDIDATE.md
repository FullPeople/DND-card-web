# QQ 账号与填写窗口 280 候选

修复登录后的账号按钮、旧卡同步勾选性能，并加入全选与全取消。导入时忽略所有未填选择；职业等级快照涵盖稍后载入的属性提升，手动恢复填写和升级新增项保留。主要页填写窗口覆盖快捷栏、特性、背景与专长及已预备法术，保留纸张尺寸与其他页面。

单机的已登录本机卡用云按钮上传；云端卡用同一按钮核对权限、管理授权或移除云端原卡。本机草稿保留。编号与复制移入账号弹窗和云端设置。枭熊房间改动继续自动写回原卡，未授权 DM 继续只读。

范围为网站 card/library 和 Suite-dev，不包含稳定插件及云端 API 升级。使用隔离工作区；原 229 份输入的实际完整审计已完成，18,789 个身份、63 个模块、6,535 个实现见证、零未决，报告绑定 Data 的不可变提交。完整本地单元检查有 1,292 项通过、91 项原有条件跳过；云端浏览器检查覆盖 48 个场景，插件使用模拟账号的页面与 HTTP 权限检查有 23 项通过。最终 CI、备份与公网发布已完成，精确来源和结果见 [280 最终回执](RELEASE-QQ-FILL280-FINAL.md)。

创作场景的旧测试数据按新导入规则恢复填写状态，真实导入检查仍保留忽略状态。单机断网检查允许同源只读 QQ 会话查询，继续禁止云端写入及房间通信。真实 QQ 扫码、房间和设备验收单独记录。服务器维护继续使用已安装的内存限制，不在服务器构建前端。
