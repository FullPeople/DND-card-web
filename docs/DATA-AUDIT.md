# 中文站资料导入排查

本轮在 `https://5e.kiwee.top` 实际获取并重新归一化资料。原目录为 7,750 条上游资料；当前为 **16,336 条上游资料 + 12 条项目体型资料**。58 个进度任务和另行读取的法术职业索引均成功，无下载失败。原始资料与审计 JSON 留在忽略的 `work/upstream-audit/`，不加入公开仓库。

## 确认的遗漏与修复

| 原因 | 本轮处理 |
| --- | --- |
| 固定下载清单未覆盖全部角色/规则数据文件 | 增加 generated variantrules、magicvariants、charcreationoptions、rewards、psionics、deities、cultsboons、bastions、tables 与 generated tables |
| 下载了文件，但只读取部分顶层数组 | 收录 itemGroup、itemMastery、itemProperty、itemType、status、disease 等分类 |
| 魔法装备以模板保存，列表中没有具体装备 | 读取 230 个模板，按基础物品条件与版本生成 4,518 个具体变体；区分基础装备与模板身份，不混合 2014/2024 |
| 只读取 entries，工具说明保存在 additionalEntries | 展示补充正文，并展开 itemEntry 引用及参数 |
| 副本只保存 _copy，原先未展开 | 处理基础继承、声明式数组增删/替换、受限文本替换、字段设置；本轮实际收录结果剩余 _copy 为 0 |
| 未命名子种族和 _versions 被忽略 | 合并父种族，再展开抽象模板/具体实现及声明式变体；保留来源版本 |
| 同名不同神系、同英文不同表格被 Map 覆盖 | 将神系、表格上下文纳入相应类别身份 |

## 尚未覆盖的站点范围

目前仍不是整个 5etools 网站的离线镜像。怪物图鉴、物件、载具、陷阱/危害、食谱/制作、卡组、遭遇生成器，以及书籍/冒险全文、fluff 插图/音频和站外自制内容尚未接入。上游新增或未支持的复杂转换指令不会被执行成脚本，也不能仅凭本轮 `_copy = 0` 推断未来资料均可完整转换。

本轮验证覆盖角色目录、正文与引用展开、源数据不被修改、版本身份、循环副本保护，以及真实站点抽查。没有宣称每项规则效果已实现自动计算；角色已保存的选择仍保留其原始快照。
