# Full Suite-dev 1.0.170 · 设置和交互精修

承接本地 168 的完整迁移，169 上线核验后由 170 补充鸣谢遮挡与旧许可文字修正。本轮用户明确授权解决问题后部署开发版。

## 设置边界

- 顶部拆分「功能开关」「设置」。23 个功能开关复用原场景/房间设置与模块生命周期，增加仓库和三龙牌；玩家只读共享开关。
- 参数页只保留界面、同步、资料权限、先攻、投骰、传送门、Boss 血条、血量气泡、动态迷雾、世界包、鸣谢。
- 删除网页设置中的旧表格下载、布局编辑/重置、资料包教程、重复版本切换、旧转场/音乐/资源浮窗入口。资料版本和来源由「规则与扩展」维护。
- UI 基准色调是个人浏览器偏好，实时影响工作台及嵌入面板；角色纸卡保留独立配色和黑色缺项边框。
- 外部网页与枭熊 iframe 的存储隔离是个人参数不生效的原因。音效、语言、气泡缩放、Boss 血条间距通过限定键的偏好通道写入宿主存储并通知原模块。
- 鸣谢复用原有姓名/头像漂浮效果，离开鸣谢后关闭；排除左侧内容区域，含暗色背景层；许可文字按网页与原套件各自适用范围展示。

## 交互和排版

- 切卡保留同一个 A4 DOM 容器，数据在绘制前替换，缩放先于绘制计算；不再把切卡误识别成新填入特性。
- 拖拽不使用浏览器原生图像。拿起、松手、取消、移除使用实际位移；落点补间保持不透明，目标格和相邻格让位。窄屏切页等待落位完成。
- 仓库和背包采用圆角物品格，标题/重量在上、数量/装备/同调在下；仓库限制视窗高度，资源卡分开标题、生命条、角色信息和消耗控件。
- 总览/投骰/音乐板在同一行居中；删除重复源码入口和右上角问号。

## 验证

- 49 项网页单元测试。
- 75 项既有工作台浏览器/SDK 协议回归。
