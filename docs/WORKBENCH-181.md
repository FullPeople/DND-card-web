# 本地 181 修订：角色同步、库存竞态与增益视觉

2026-09-24，独立修错发布候选。线上基线1.0.180-dev；用户明确排除本轮新增Buff。

## 本次实机问题及修复

1. **角色内容不互相同步。** Suite 宿主对旧跨房角色从原上传地址读取，却向当前房间保存，造成两个副本分岔。现在读、写、失败回读、删除都使用同一文档地址。另修复已知较新版本仍无条件接受旧 ETag 的 304。真实 SDK 双宿主本地夹具先复现旧代码错写，再确认姓名、职业、背景、种族、法术原生/旧格式都能在另一宿主停留当前卡时更新；不是只模拟广播事件。
2. **状态增删白屏。** 快速 ACK 目录把旧钱包 `{wallet:{gp,pp,ep,sp,cp}}` 当作平面币种，React 尝试渲染对象。宿主和网页同时规范化，旧钱包导入/初始库存也保留币数。已有错误建账不能从旧钱包盲目补币，避免把已消费货币重新加入。
3. **换格报冲突并回退。** 库存操作保持立即预览，但顺序提交；发送时重建可安全更新的版本基线。换格提供 `observedSlots`，宿主校验相关格位而非因无关数量变化拒绝整包。乐观覆盖只写改动字段、不遮盖新数量或锁定、不复活已转移行；回执整批通知订阅者，避免旧中间帧。原生库存投影和网页 hydration 都保存格位。
4. **旧场景与迟到确认。** 草稿只叠加到同一仓库作用域，命令带 scopeKey；旧场景回执不能切回仓库或恢复旧权限。未知结果后来确认成功会补一次撤销记录，重复回执不重复记录。
5. **提示影响排版。** StockBoard 使用现有全局浮层和可复制诊断，不插入背包布局。资源播报在提交成功后、棋子视觉投影前发送；提示 iframe 场景就绪即预热，空闲不重建；READY/ACK、去重、隐私和场景销毁保留。首次提示音初始化排到首帧之后。
6. **法术格。** 普通高度 14→28px、窄屏 24→48px，保持一行五格、名字省略，右侧恢复 0～9 环阶数字。没有恢复用户已删除的法术页法术位区；原有资源中的法术位消耗逻辑不变。
本轮新增28套Buff视觉、内置增益目录和效果模板选择器未纳入发布候选；相关本地开发单独保留。180已有状态视觉继续使用。
