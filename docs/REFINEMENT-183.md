# 183：快捷栏、法术与单机版

- 主要页按施法制度显示已预备或全部已学法术。
- 快捷栏引用是独立副本，不再通过固定条目暗中授予职业、特性等规则。编辑模式顶部管理条提供自定义命中/伤害以及逐资源配置。
- 玩家资源与卡上法术位复用同一摘要/弹层。消耗保持原资源身份和连续修改队列。
- 原始 `preparedSpellsProgression` 或 `preparedSpells` 算式给出预备基数，手动字段是调整值。安全算式解释器不执行资料中的 JavaScript。超额加入被拒绝，降低上限时已存在法术保留供人工调整。未知基数不伪造职业配额，旧绝对上限可迁移。
- 预备框显示三行，攻击/DC调整移到数值右侧；仪式蓝色渐变、专注虚线。
- SCAG 亚种族在 2014 卡且来源启用时经浏览器拖拽验证。版本门禁只针对 PHB/XPHB、DMG/XDMG；未启用来源和单独禁用条目仍受限制，失败落点会显示原因。
- 单机构建及使用方式见 STANDALONE.md。

宿主连续修改的延迟路径及测试在 Suite `docs/WORKBENCH_RESOURCE_183.md`。回归仍用受控宿主和消息乱序模型，不能代替真实多人房间网络测量。

验证：117 项核心测试；8 项本轮法术/快捷栏/SCAG浏览器测试；生产单机离线测试。发布流水线另执行当前维护的连续资源、库存冲突、迟到回执和远端更新验收组。历史布局/旧交互用例仍保留在 tests/e2e，`npm run test:e2e` 可运行完整历史集合，其中旧选择器不作为本次发布门槛。
