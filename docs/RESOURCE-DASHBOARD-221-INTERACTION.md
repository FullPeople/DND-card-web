# 2026-10-01 · 仪表盘排版手感（本地工作批次 221）

用户本轮要求允许临时重叠但禁止保存重叠布局，移动不挤开其他模块，并支持从模块库拖入自绘幽灵预览。沿用 220 的 16 款模块、同尺寸画布和隔离工作树，没有重新开发样式库。

## 当前行为

- 仪表盘为独立草稿：新增、移动、八点缩放、配色与单项设置均先留在本地草稿。点击“保存布局”才提交，关闭窗口或“放弃修改”不修改角色卡。
- 模块可以自由重叠。冲突模块标红，保存按钮禁用；检查涵盖所有页，同页边缘相接不算重叠。移动、缩放和新增仅调整目标，邻居与武器模块不被挤开。
- 已保存坐标在编辑器和主卡面按相同规则显示，不再由自动排版改写。高密度资源组的最小尺寸按实际内容约束，保证法术环位与子项可读；内容增长仅影响自身最低尺寸，不重排邻居。
- 模块库使用 Pointer Events 自绘实际模块的半透明幽灵、网格落点与冲突提示，不使用浏览器原生拖拽影像。画布内松手仅创建一次；画布外松手、Esc、指针取消、窗口失焦均取消。点击和键盘添加继续可用。
- 保存将草稿改动与最新角色合并；未修改的资源余额、生命值与其他角色字段保留。冲突、权限变化及合并后的重叠会拒绝保存，不提交部分修改。此处的并发安全经过合成数据单元测试，未据此声称真实多人宿主已验收。
- 保存状态占位固定，不引起对话框跳动。拖动幽灵不再每帧深拷贝整张角色卡，草稿比较只在实际修改时进行。
