# 生命值联动小原型

这是无新增云端同步服务器的通信原型，不是完整角色卡联动功能。只修改用户明确选择的一个棋子的当前生命值，不上传 / 替换完整人物，不修改 Full Suite。

## 现在就看模拟

运行 `npm run dev:sync-prototype` 后访问 http://127.0.0.1:5189/demo.html 。模拟台点击「打开联动角色卡」会打开独立浏览器窗口，两边分别修改生命值即可观察同步。测试选项可将角色卡地址改成 http://localhost:5189/card.html ，验证不同源。

发布给本机用户的 ZIP 已包含构建页面、启动脚本和 Node 静态服务，不需要 npm install。解压后双击「启动原型.cmd」。本机需要 Node.js；当前开发电脑已经安装。此程序仅提供网页文件，不保存或转发生命值同步消息。

## 你在真实枭熊里怎么试

1. 保持本地原型运行，用正常已登录的浏览器进入你提供的测试房间。
2. 在枭熊扩展管理中添加 `http://127.0.0.1:5189/manifest.json`，并在该测试房间启用。如果浏览器询问本地网络访问或弹窗权限，允许这次本机测试。
3. 用原有 Full Suite 给一个测试棋子设置当前生命和生命上限，然后只选中这个棋子。建议先用 DM 身份。
4. 点击新出现的「生命同步原型」扩展按钮，然后点击「打开联动角色卡」。这是独立的简化生命值卡，不是正式 A4 卡。
5. 独立窗口点 −1，查看 Full Suite 的血量；反过来在 Full Suite 修改当前生命，查看独立窗口。临时生命、最大生命、隐藏设置应保持不变。
6. 关闭枭熊里的插件入口面板，继续两边修改；刷新独立窗口，应恢复连接。
7. 刷新枭熊房间页面，独立窗口应在约 4 秒后显示断开、停止写入。重新从插件按钮打开新窗口即可继续。旧窗口不能自动覆盖场景。
8. 测完关闭窗口并移除这个独立原型扩展即可。它不修改正式插件代码；已经实际应用的 HP 修改是场景数据，需要自行恢复测试棋子的血量。

本地地址只对当前电脑有效，不能把它发给其他玩家作为公网地址。多人测试可将 `site` 的静态文件发布到现有网站的独立目录，让每人安装那个 manifest；仍无需新增同步后端，但此次没有执行发布。若 Owlbear 或浏览器拒绝 HTTP 本地扩展，则下一步使用现有网站的 HTTPS 静态目录，不应绕过安全验证。

## 原型范围和验证证据

使用官方 SDK 3.1.0。正式适配读取 `com.obr-suite/bubbles/data`，兼容旧气泡 key；只更新 health，保留临时生命、上限和其他 metadata。GM 或匹配的棋子 / 卡片拥有者可访问，私有 DM 卡不开放给普通玩家。

入口 iframe 同步打开窗口以保留用户点击的弹窗权限；随后向常驻后台授权一次性会话。窗口通过来源限定的 postMessage 握手，后台持有独立窗口引用，所以入口面板销毁不会中断连接。后台定时发送心跳，独立窗口刷新可以恢复；房间整体重载会丢弃临时授权，要求重新打开。会话 2 小时到期。

5 项 Edge 浏览器模拟测试通过：跨域双向；销毁入口和刷新卡片；重载宿主后断开 / 新连接；场景移除和撤销权限；重复操作、过期修订、错误来源 / 窗口 / 会话拒绝；缺少会话与弹窗拦截提示。3 项 SDK 适配模拟单元检查通过：仅写 HP 保留其他字段、归属与隐私、过期值与场景代次拒绝。

测试使用真实浏览器窗口、不同源和带 sandbox 的 iframe，但 scene API 使用模拟数据。未完成真实 Owlbear 房间验收。自动浏览器访问提供的测试房间遇到 Cloudflare 验证；随后用户明确要求只做模拟，留待自己实测。

本地同一后台中的请求排队、去重与版本检查不等于跨多个玩家并发写入保证。其他插件直接并发改同一棋子的 metadata 仍有后写覆盖风险。此轮验证的是窗口链路，不承诺整卡同步、跨设备、自动恢复房间重载、多玩家并发无损或长期云端存档。HP ±1 是直接调整当前生命，不包含临时生命抵伤规则。

## 开发命令

```text
npm run dev:sync-prototype
npm run build:sync-prototype
npm run test:sync-prototype
npx vitest run tests/windowPrototype.test.ts
```

原型使用独立 Vite 配置与输出 `dist-sync-prototype`，不改变正式网页入口与构建。安装 SDK 为开发依赖，用于原型打包。

官方开发参考：[本地开发与 CORS](https://docs.owlbear.rodeo/extensions/tutorial-hello-world/create-your-site/)、[场景条目 API](https://docs.owlbear.rodeo/extensions/apis/scene/items/)、[窗口通信](https://developer.mozilla.org/en-US/docs/Web/API/Window/postMessage)。
