测量说明

“界面提交”是点击处理开始到同步内容更新完成；“下一帧”包含浏览器帧调度，不代表精确像素绘制时间。准备耗时单独记录。

“外层卡面提交”只统计实验卡面外层 React 组件的布局提交，未覆盖所有子组件或 React 根提交。“外层挂载／卸载”只统计外层包装组件的生命周期。第 2～4 层会复用外层组件，因此它们也可能保持零挂载、零卸载，同时重新求值、提交或替换内部 DOM；这与第 5 层保留全部卡面有不同含义。

“DOM 元素增／删”统计卡面区域新增或移除的元素及其后代，不统计文字、属性或样式变更。第 5 层切换可见性和 inert 属性也不计入增删。导出的总计包含准备阶段，每条切换记录只统计本次切换到第一帧观测之间的变化。示例结果不能代替真实卡或其他设备验收。
