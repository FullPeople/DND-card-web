# 角色卡启动动画与大厅原型（v4）

保存已确认的启动体验，供后续接入角色卡产品使用。

## 运行

直接在现代浏览器中打开 `index.html`。这是完整离线单文件，无构建步骤、外部依赖或网络请求。图片已嵌入 HTML；`assets/` 另保留相同的四张原 PNG，方便后续复用。

## 当前行为

- 四个完整图层按不同方向位移、旋转入场，并从透明逐渐变为不透明；最终回到原始位置和角度。
- 入场错峰为 0 / 0.14 / 0.28 / 0.42 秒，每层动画 1.9 秒，约 2.65 秒后进入大厅。
- 支持跳过、重播及系统“减弱动态效果”。
- 大厅包含示例角色的选择、分类、搜索和详情弹窗，提供桌面与窄屏布局。

## 素材

| 文件 | 内容 |
| --- | --- |
| `assets/1.PNG` | 棋子、剑与圆台 |
| `assets/2.PNG` | 彩色小节点分子结构 |
| `assets/3.PNG` | 蓝色骰子 |
| `assets/4.PNG` | 用户补全的棋盘，包含原有黑色外沿 |

四张 PNG 均为原始 500×500 画布，保留原 RGB、透明度及坐标。合成顺序为 4 → 1 → 2 → 3，使用同一画布比例缩放。不要裁边、拉伸单个图层，或根据透明像素里保留的 RGB 扩张轮廓。

## 后续产品接入

这是独立原型，不会读写现有角色卡，也没有真实注册、登录、账号同步或后端。当前三张角色卡均为演示数据，账号方案仍待产品确认。

接入时可先复用开屏结构、动画样式和跳过/重播逻辑，再将大厅中的 `characters` 示例数组及详情弹窗替换为真实角色卡数据和页面入口。真实权限、数据保存、异常处理和账号设计需在产品实现时另行完成。

本目录不改变主应用路由，不自动合并代码或部署服务；也不包含聊天头像/宠物动画。

## 校验

安装 Node.js 后，在此目录运行：

```sh
node verify.mjs
```

校验脚本检查已确认 HTML 的 SHA-256、四张原图尺寸和字节，以及 HTML 内嵌图层与导出 PNG 是否一致；同时检查脚本语法、入场初始透明和最终归位状态。

静态透明度合成和上述源码/字节检查已完成。浏览器连续播放、移动端交互及与真实应用集成，仍需在目标产品环境中验收。
